# 詞彙表

Substance 3D Painter 是一款 3D 應用程式，依賴許多技術和技術關鍵字，起初可能難以理解。\
本頁列出該應用程式最常用的關鍵字，並附有其背後概念的簡短說明。

| *關鍵詞* | *定義* |
| --- | --- |
| **路線** | 對齊是指畫筆在上色時會如何朝向 3D 網格。 |
| **阿爾法** | Alpha 是一種遮罩，可以用來繪製細節或複雜形狀，例如條碼或標誌。 |
| **烘焙** | 烘焙（或稱烘焙）是指從 3D 網格中計算資訊，並根據網格的 UV 資訊將其儲存成貼圖的動作。 |
| **位元深度** | 位元深度是指貼圖中（每種顏色）可儲存的資訊量。 數字越高，資訊的精確度越高。 然而，當計算時，效能會隨著數字越高而下降。 |
| **刷子** | 刷子是一種用來在網格上作畫的工具。 筆刷由多個參數定義，這些參數控制其行為（例如大小與透明度）。 |
| **相機** | 攝影機是能控制你在3D或2D視窗中觀看位置和方向的物件。 |
| **頻道** | 通道是一種具有特定行為的紋理。 有些通道用來定義材料的顏色，有些通道則用來控制表面上的光行為。 |
| **複製人** | 克隆是一種用來在其他地點複製部分繪畫或材質的工具。 |
| **內容 / 面具** | 內容與遮罩指的是圖層的兩個主要特性。 內容是儲存在圖層中通道中的實際繪畫，而遮罩則用來顯示或隱藏內容。 黑色遮罩等同於隱形內容。 |
| **擴散** | 擴散是一種在網格紫外線島外產生資訊的方式。 它的原理是將靠近 UV 島邊界的最後像素流出，產生模糊的顏色。 |
| **擴張/填充** | 與擴散原理相同，膨脹是一種透過延伸像素顏色來產生紫外線島外資訊的方法。 |
| **影響** | 效果是可以加在圖層上的元素，無論是內容還是遮罩上。 Substance 3D Painter 支援各種效果，例如濾鏡。 |
| **環境** | 環境是一種用來計算場景光照的影像，通常是代表廣泛色彩資訊的 HDR 材質。 |
| **出口** | 匯出的動作是從應用程式中實現的繪畫產生扁平紋理的方式。 從匯出產生的貼圖可用於其他應用。 |
| **視野 / 視野範圍** | 視野範圍是相機可觀察世界的範圍。 |
| **填土** | 填充是一個動作（可以是效果或圖層），可以將顏色、貼圖甚至材質載入整個 3D 網格。 |
| **濾波器** | 過濾器是一種物質效果，可以修改先前的資訊。 例如，模糊濾鏡會軟化先前的影像。 濾波器也可能更複雜，並會修改整個材質。 |
| **過濾** | 過濾指的是貼圖在 3D 視窗中顯示的方式。 最常見的是最近（像素按原樣讀取，使近距離影像呈現方塊狀）和雙線性（像素插值，近距離影像顯得模糊）。 |
| **GPU** | 圖形處理單元（GPU）是電腦中執行快速運算以產生影像的部分。 |
| **發電機** | 產生器是一種物質，通常基於額外的紋理產生新的資訊或影像。 例如，有些遮罩產生器會用烘焙貼圖來建立複雜的遮罩。 |
| **直方圖** | 直方圖是一種色彩值分布的圖形表示。 它用來視覺化影像中陰影、中間調與高光之間的色彩平衡。 |
| **伊雷** | Iray 是由 NVIDIA 開發的路徑追蹤渲染器，用於在 3D 網格上投射逼真的光照。 因為它是進階渲染器，設計用來製作漂亮的影像，並非用於即時工作。 |
| **抖動** | 抖動是畫筆在繪畫時產生隨機行為的特性。 |
| **層** | 圖層是一種包含多個通道的元素，具有混合模式和不透明度等額外特性。 |
| **層堆疊** | 圖層堆疊是一個可以管理和組織圖層的地方。 層級依底層至上排列。 底層會先畫，然後再把上面的每一層一層疊加在另一層上。 |
| **懶鼠** | 懶惰滑鼠是刷子工具的一種行為。 它會放慢筆觸路徑以提升繪畫的精準度，並在滑鼠游標和實際繪畫之間產生延遲/偏移。 |
| **關卡** | 等級是一種效果，可以透過直方圖來控制範圍或色彩/灰階資訊。 例如，它可以用來反轉顏色或使顏色變暗/變亮。 |
| **日誌** | 日誌是一種文字檔，裡面記錄了軟體中寫入的資訊，通常與執行該應用程式的電腦相關。 |
| **低/高多邊形網格** | 低多邊形網格和高多邊形網格都是 3D 網格，一個多邊形密度較低，另一個則多邊形數量較高（通常大 100 倍）。 通常高網格資訊會被烘烤到低網格。 |
| **材料** | 材料定義了代表特定物質的性質。 在 3D 網格中，材質也用來定義多邊形面的群組。 |
| **網狀** | 網格是由多重資訊定義的三維物件。 在 Substance 3D Painter 中，網格是由多邊形（通常是三角形）定義的。 網格可以在 3D 建模應用程式中建立，例如  **Blender**  或  **Autodesk Maya**  。 |
| **網格貼圖** | 網格貼圖是從網格烘焙而成的貼圖，包含相對於網格的資訊。 例如，它可以是位置資訊或遮蔽資訊。 |
| **Mip-Map** | mip-map 是一種預先計算好的紋理，通常每次以低於原始紋理解析度的影像序列形式呈現。 |
| **模式** | 模式指的是介面的設置，依模式不同，提供特定工具與控制的存取。 |
| **噪音** | 雜訊是一種程序化且隨機的影像，通常代表有機形狀及色彩/灰階值。 |
| **正常** | 法線是一種特殊的貼圖，會變形光線在 3D 網格表面的行為，以模擬幾何體中不存在的細節。 |
| **OpenGL / DirectX** | OpenGL 與 DirectX 皆為用於渲染 2D 與 3D 資訊的應用程式介面（API）。 它們也定義了法線貼圖格式。 |
| **正字法** | 正投影是一種在二維空間中表示三維物體的方法，其中所有投影線都與投影平面垂直。 |
| **PBR / PBS** | 物理基礎渲染（Physically Based Rendering，簡稱 PBR）或物理基礎著色（Physically Based Shading，簡稱 PBS）是一種電腦圖學模型，旨在以更準確的方式渲染圖形，以更準確地模擬現實世界中光線的流動。 |
| **打包** | 打包是指將多張影像儲存在一個貼圖中。 由於貼圖由分離的紅、綠、藍通道組成，它們可能儲存不同資訊，這些資訊可在其他應用程式中獨立讀取。 |
| **粒子** | 粒子是一種根據物理特性或其他複雜行為產生筆觸的工具。 |
| **觀點** | 透視是指人眼在平面（如螢幕）上所見的近似表現或物體或場景。 這是深度與規模的模擬。 |
| **像素 / 紋素** | 像素是影像中的一個點，是包含顏色資訊的最小元素。 解析度越高，可用的像素越多，能提供更清晰的解析度和更多細節。 Texel 是貼圖裡的像素。 |
| **插件** | 外掛是可加入軟體的程式設計函式（通常透過腳本表達），擴展應用程式的可能性。 |
| **後製程** | 後製處理是在3D影像渲染完成後，施加在螢幕上的一種視覺效果，通常用來模擬特殊行為，如色彩校正或泛光。 |
| **程序性** | 程序式是指由電腦根據一系列參數產生的過程。 它可以是簡單的數學結果，例如數字或複雜的圖像。 |
| **投影** | 投影是指從特定視角（例如攝影機）將影像/物件套用到3D網格表面的動作。 |
| **解析度（2的冪次方）** | 解析度定義了貼圖在 X 軸和 Y 軸（或寬度與高度）上的大小。 通常以2的冪次方（2、4、8、16......512、1024、2048......）來形容。 因為它是針對 GPU 運算進行優化的。 |
| **腳本編寫** | 腳本是透過文字檔案格式使用特定指令來執行特定行為的行為。 |
| **著色器** | 著色器定義材質在接收光照資訊時的行為。 有些著色器可以很簡單（像是卡通陰影），也可以更進階（像是模擬表面光線吸收的皮膚陰影）。 |
| **書架** | 書架是應用程式中多種資源集中存放的位置。 它可以從簡單的圖片到更複雜的工具。 |
| **智慧口罩** | 智慧遮罩的行為類似智慧材質，但它們不是層狀，而是根據目前 3D 網格定義的效果，只產生遮罩。 |
| **智慧材料** | 智慧材質是一組儲存為一個檔案的圖層。 智慧材質可以根據 Substance 3D Painter 的每個專案進行調整，讓材質會根據當前 3D 網格而改變。 |
| **污漬** | Smudge 是一種用於滲色、擴散或混合顏色的工具。 它常用於軟化像素。 |
| **模板** | 模板是將影像對準螢幕，並搭配攝影機投影在3D網格上繪製。 |
| **內容** | Substance 是一種檔案格式，允許根據一組參數（涉及程序式計算）產生紋理。 這些參數可以被修改以產生變化。 |
| **對稱性** | 對稱是一種工具的選項，可以同時在鏡子裡兩個地方作畫。 |
| **範本** | 範本是一組預先定義的選項，用於建立新專案時使用。 例如，它可以定義預設解析度或預設烘焙設定。 |
| **Texel 比率** | 像素比是比較 UV 島（2D）大小與相關 3D 網格幾何形狀的規則。 良好的 texel 比率意味著二維幾何體的展開均勻。 這對於保持3D網格上繪畫/貼圖品質的一致性非常重要。 |
| **材質** | 紋理是一個包含由解析度定義的二維像素的檔案。 像素可以是灰階或彩色。 當像素被著色時，可以有透明度資訊（如果檔案格式支援的話）。 |
| **材質集** | 在 Substance 3D Painter 中，貼圖集代表網格中特定 UV 需要繪製的部分。 貼圖集是根據匯入 3D 網格時偵測到的獨特材質建立的。 |
| **耕作** | 耕作是重複紋理，邊界處看不見接縫，目的是模擬無限平面。 例如：草地或人行道。 |
| **工具** | 工具指的是一種動作，允許與 3D 網格互動，通常是用來繪製或套用特效。 |
| **工具列** | 工具列是所有工具捷徑圖示的所在位置。 |
| **UDIM** | UDIM 是一種將 3D 網格的 UV 分割到多個範圍，以提升整體材質解析度的方法。 |
| **紫外線** | UV 是定義在 3D 網格上的資訊，指示如何展開成平面形狀。 這些資訊用來將貼圖投影到3D網格上。 Substance 3D Painter 只允許在代表貼圖大小的 0-1 範圍內繪製。 其他範圍僅支援 UDIM 系統。 |
| **VRam** | VRam 是 GPU（顯示卡）的記憶體，用於在進行運算時儲存資訊與紋理。 VRam 越高，使用 Substance 3D Painter 越好。 |
| **觀景窗** | 視窗是顯示 3D 或 2D 場景在螢幕上的位置。 這也是可以透過控制相機與工具和 3D 網格互動的地方。 |
