# 子圖書館分頁

子函式庫是 Substance 3D Painter 中專門用於特定搜尋的新分頁或視窗。\
預設沒有子庫分頁，只有主資產視窗。 你可以從主資產視窗用兩種方法建立子庫分頁：

* 透過  **右鍵點擊**  儲存的搜尋並選擇 **「建立新分頁」。**

![](../../assets/08-01-sublibrary.jpg)

* 選擇  **或輸入搜尋查詢** （透過資產類型、麵包屑、文字查詢或路徑篩選），然後使用資產視窗底部的專用  **按鈕**  。

![](../../assets/08-02-sublibrary.jpg)

建立子庫會自動建立一個新分頁，並將其  **停放在**  介面中與主資產視窗相同的空間。

從那裡，子圖書館視窗可以停靠到其他任何地方，或是自由漂浮在介面中的任何一個或另一個畫面上。

>[!NOTE]
>
> * 子函式庫與主資產視窗功能相同，但重置後會回復到原始搜尋查詢。
> * 與主資產視窗不同，如果你關閉子函式庫，它就必須重新建立。
> * 若已儲存的搜尋被移除，子圖書館視窗將持續存在直到關閉。
