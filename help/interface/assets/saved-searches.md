# 已儲存的搜尋

儲存搜尋與路徑篩選是另一個可在資產視窗中開啟的新區塊。 它讓你能儲存最常搜尋和查詢的內容，隨時輕鬆存取，甚至以新的子圖書館分頁開啟，並可獨立停靠。

![](../../assets/02-01-savedsearches.jpg)

要建立已儲存的搜尋，可以結合不同類型的導航方式——你可以在搜尋欄輸入書面查詢，選擇想要的資產類型（或多種資產類型），並透過路徑篩選或麵包屑選擇位置。 這些都可以儲存為單一已儲存的搜尋，或拆解成獨立的儲存搜尋。 例如，你可能想建立一個儲存搜尋，搜尋使用 Dynamic Stokes 的筆刷，因為你經常用到這個工具。

>[!NOTE]
>
> 儲存的搜尋會儲存在設定檔中，可以手動編輯。 欲了解更多，請參考 [「手動](../../pipeline-and-integration/resource-management/adding-saved-searches-manually.md)新增已儲存搜尋」。

一旦你建立了儲存的搜尋，它就會顯示在你的搜尋清單中。 你可以右鍵點擊它來建立新的子函式庫分頁、重新命名或刪除它。

![](../../assets/02-02-savesearch.gif)

您也可以透過將滑鼠移至搜尋欄中的搜尋標籤上，查看搜尋內容的資訊。

![](../../assets/02-03-searchinfo.jpg)
