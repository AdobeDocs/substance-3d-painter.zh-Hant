# 路徑過濾

**「路徑** 篩選」是額外的區塊，可以用來瀏覽你的資產。 它的結構和麵包屑一樣，代表它能讓你看到資產的路徑和位置。

![](../../assets/01-01-panel.jpg)

預設情況下， **隱藏非適用資料夾** 會啟用，讓你能從介面中隱藏空資料夾。 例如，如果你將路徑篩選與特定搜尋詞結合，或選擇資產類型，這會很方便——它只能讓你看到包含搜尋的相關位置。

![](../../assets/01-02-hideempty.gif)
