# 自訂版面配置

有一些介面選項，例如子函式庫、縮小寬度和縮圖大小，讓你能依需求調整資產面板配置。

>[!NOTE]
>
> 素材可以透過滑鼠滾輪或操作滾動條來滾動，或者另一種在任一畫家視窗中滾動的方式是 **維持 Ctrl + Alt 並拖曳** 在想要的面板內。

對接與定向

安裝後第一次開啟 Painter 時，你會發現 Asset 視窗垂直停靠在應用程式左側。 不過它可以脫離對接並水平放置。 如果你使用額外的 [子圖書館](sub-library-tab.md) 視窗，它們也能隨意插入或拔除底座。

![](../../assets/00-02-docking.gif){width="600px"}

## 寬度降低

其大小可縮小，資產類型會整合成單一選單，讓你可選擇一個或多個選項。

![](../../assets/00-03-reduced.jpg)

## 縮圖尺寸

資產縮圖大小可透過最左邊的圖示調整，該圖示提供小型、中型（預設）、大型與清單等選項。

![](../../assets/00-04-thumbs.jpg){width="600px"}
