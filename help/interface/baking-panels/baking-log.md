# 烘焙木頭

**烘焙日誌面板**&#x200B;顯示與烘焙相關的技術輸出。面板包含三個分頁：

* **烘焙過程**：查看正在進行的烘焙任務狀態或最近的烘焙進度。
* **高多邊形參數**：查找專案中使用的高多邊形檔案細節。
* **以名稱**&#x200B;匹配：當 **高多邊形參數>匹配** 設定為 **依網格名稱**&#x200B;時，這個分頁會顯示資產如何匹配的資訊。

>[!TIP]
>
> 關於如何依名稱匹配資產的資訊可在 Bakers 文件](https://experienceleague.adobe.com/en/docs/substance-3d/bakers/features/matching-by-name)中找到[。
