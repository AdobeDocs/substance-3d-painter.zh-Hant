# 視窗選單

![](../../assets/viewport-menu.png)

視窗選單可用來更改視窗](https://substance3d.adobe.com/)的[顯示模式。

| 動作 | 說明 |
| --- | --- |
| **展示資料** | 切換視窗到 **Material** 模式，顯示帶有光影和陰影的 3D 模型。 |
| **顯示下一個頻道** | 將視窗切換到單人模式，以顯示下一個材質集通道。 |
| **顯示前一頻道** | 將視窗切換到單獨模式，以顯示先前的材質集通道。 |
| **顯示下一個網格貼圖** | 將視窗切換到單人模式，以顯示下一個烘焙的網格貼圖類型。 |
| **顯示先前的網格地圖** | 將視窗切換到單人模式，顯示先前烘焙的網格貼圖類型。 |
| **顯示整個網格** | 調整視窗攝影機，使其對準 3D 模型。 |
| **啟用快速遮罩** | 更多資訊請參閱 [快速口罩](../../painting/tool-list/quick-mask.md) 頁面。 |
| **編輯：快速遮罩** | 更多資訊請參閱 [快速口罩](../../painting/tool-list/quick-mask.md) 頁面。 |
| **反轉快速遮罩** | 更多資訊請參閱 [快速口罩](../../painting/tool-list/quick-mask.md) 頁面。 |

欲了解更多顯示模式資訊，請參閱 [顯示設定](../display-settings/display-settings.md)。

欲了解更多快速面罩資訊，請參閱 [專頁](../../painting/tool-list/quick-mask.md)。
