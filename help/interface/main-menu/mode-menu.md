# 模式選單

![](../../assets/image2018-5-28-16-58-24.png)

在模式選單中，你可以切換不同介面來處理不同的任務。 每個模式都有專屬的用途和介面，其他模式無法存取。

| 動作 | 說明 |
| --- | --- |
| **烘焙網格貼圖** | 使用此模式來建立像法線、世界空間法線、AO 和 ID 等實用貼圖，可以從高多邊形烘焙到低多邊形，或直接使用專案網格本身。 |
| **繪畫** | 你會在 Painter 裡花大部分時間，在繪圖模式中可以存取圖層堆疊和材質，直接在 3D 模型上繪製。 |
| **渲染（Iray）** | 切換到 Iray 渲染模式。 Iray 是一款非即時渲染器，可以產生高品質的渲染。 更多資訊請參閱專頁： [Iray Renderer](../../features/iray-renderer/iray-renderer.md)。 |
