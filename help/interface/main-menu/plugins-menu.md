# JavaScript 與 Python 外掛選單

![](../../assets/plugins-javascript.png)

JavaScript 和 Python 選單列出 Painter 啟動時載入的所有外掛。 外掛會根據所使用的腳本 API（Javascript 或 Python）分為兩個選單。

應用程式發現的每個外掛都會在相應選單中新增一個項目，以存取更多功能。 在選單中，每個外掛都有以下選項：

* **啟用/啟用**：切換外掛的開關。
* **RELOAD**：如果腳本在應用程式執行時被更新，請重新載入外掛。
* **Configure**：如果外掛支援，會顯示外掛功能/視窗來設定外掛。
* **關於：**&#x200B;若外掛支援，則顯示外掛相關資訊。

想了解 Painter 提供的預設外掛，或如何自己創建新外掛，請參考專門的 [外掛](../../features/plugins/plugins.md) 頁面。
