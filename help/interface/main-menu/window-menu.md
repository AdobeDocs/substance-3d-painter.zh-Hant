# 視窗選單

![](../../assets/window-menu.png)\
視窗選單可顯示視窗列表，以及介面中是否可見。 你也可以用工具列選單來隱藏一些工具列。

| 動作 | 說明 |
| --- | --- |
| **觀點** | 列出介面中可用的視窗（勾選框顯示目前是否可見）。 |
| **工具列** | 列出介面中可用的工具列（勾選框顯示目前是否可見，允許切換）：Docks、Plugins 與 Tools。 |
| **隱藏使用者介面** | 它會隱藏介面上的所有視窗和底座，並最大化視窗。 |
| **重置使用者介面** | 將目前的視窗配置重設為預設值。 |
