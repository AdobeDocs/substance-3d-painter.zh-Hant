# 檔案選單

![](../../assets/file-menu.png){width="150px"}

檔案選單包含建立與儲存專案的動作，以及匯出和匯入資源到專案的動作。

| 動作 | 說明 |
| --- | --- |
| **新** | 開啟新的專案建立視窗。 更多資訊請參見： [專案創建](../../getting-started/project-creation.md)。 |
| **開場** | 在磁碟上開啟一個現有的專案檔案。 |
| **近期檔案** | 列出所有近期開放的專案。 |
| **開放樣本** | 打開應用程式附帶的範例專案。 |
| **結束** | 關閉目前已開放的專案。 |
| **存檔** | 先保留目前的專案。 |
| **儲存與壓縮** | 先把目前的專案存檔並壓縮（減少磁碟空間）。 |
| **另存為** | 將目前的專案存成新名稱和新地點。 |
| **儲存為副本** | 將目前的專案存成新名稱和新位置的副本，並保持目前專案開啟。 |
| **儲存為範本** | 將目前的專案設定儲存到一個範本檔，方便新專案使用。 |
| **乾淨** | 移除目前專案中未使用的資源（該資源會在下一次  **存檔**&#x200B;後生效）。 |
| **進口資源** | 打開匯入資源視窗。 |
| **匯出網格** | 打開能將目前專案匯出為 3D 模型檔案的網格匯出視窗。 |
| **匯出材質** | 打開貼圖匯出視窗，讓目前專案匯出成點陣貼圖貼圖。 |
| **發送至** | 列出所有 **將專案送至其他應用程式的 Send To** 動作。 |
| **辭職** | 關閉應用程式。 如果目前專案有未儲存的變更，系統會提示訊息。 |

>[!NOTE]
>
> 保存專案有兩種方式：
> 
> * **增量**  ：預設方法，用於一般存檔。 只有變更的資訊會更新在磁碟上的專案檔案中。 此方法允許在不重寫專案檔案的情況下，非常快速地儲存專案。
> * **完整 / 壓縮**  ：若執行清潔操作或以「Save And Compact」動作儲存專案，該方法將整個磁碟上的專案重寫。 此方法能消除專案碎片化並減少足跡。 看： [專案真的很大](../../technical-support/workflow-issues/project-issues/projects-are-really-big.md)。
