# 編輯選單

![](../../assets/edit-menu.png)\
編輯選單可以快速存取復原/重做操作，也能進入專案設定和全域設定。

| 動作 | 說明 |
| --- | --- |
| **還原** | 往[&#128279;](../history.md)歷史堆疊中退一步。 |
| **重來** | 在歷史[&#128279;](../history.md)堆疊中再往前邁一步。 |
| **專案配置** | 打開 [目前專案的專案設定](../project-configuration.md) 視窗。 |
| **場景設定** | 打開一般 [應用程式設定](../settings/settings.md) 視窗。 |
| **烘焙網格貼圖** | 打開 [烘焙](../../baking/baking.md) 窗口。 |
