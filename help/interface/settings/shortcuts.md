# 捷徑

![](../../assets/settings-shortcuts.png){width="400px"}

本頁列出所有可用的鍵盤與滑鼠快捷鍵。

## 捷徑概述

想快速了解所有可用的捷徑，請參考我們教學[&#128279;](https://helpx.adobe.com/tw/substance-3d/unlisted/tutorials/courses/substance-3d-painter-keyboard-shortcuts.html)中的圖表。

## 如何更改捷徑

![](../../assets/shortcut-edit.gif)點擊捷徑旁的「筆」圖示來編輯並輸入新的密碼。按下最後一個鍵會自動退出編輯模式並更改捷徑。

## 不可編輯捷徑列表

有些捷徑可能&#x200B;**只有在**&#x200B;滑鼠位於&#x200B;**特定視窗上方才有效**。

範例：複製貼上&#x200B;**需要滑鼠在**&#x200B;圖層堆疊&#x200B;**上**&#x200B;方。**&#x200B;**

| *行動* | *捷徑（Windows）* | *捷徑（MacOS）* | 說明 |
| --- | --- | --- | --- |
| **複製層** | Ctrl+C | ⌘+C | 複製目前選取的圖層。 |
| **切割層** | Ctrl+X | ⌘+X | 切割目前選取的圖層。 |
| **黏貼層** | Ctrl+V | ⌘+V | 將該圖層貼上記憶體。 |
| **刪除層** | 刪除 | 刪除 | 刪除目前選取的圖層。 |
| **重複層** | Ctrl+D | ⌘+D | 複製目前選取的圖層。 |
| **群層** | Ctrl+G | ⌘+G | 把目前選取的圖層放進資料夾。 |
| **複製層內容** | Ctrl+Shift+C | 選項+⌘+C | 複製圖層內容（繪畫）及其效果。 |
| **貼上圖層內容** | Ctrl+Shift+V | Option+⌘+V | 將目前記憶體中的內容（繪畫）和效果貼上。 |
| **視窗中的顯示遮罩** | Alt+滑鼠左邊 | 選項+滑鼠左邊 | 將視窗顯示模式切換到指定圖層的遮罩模式。 |
| **停用/啟用遮罩** | Shift+滑鼠左鍵 | Shift+滑鼠左鍵 | 切換遮罩在圖層上的狀態。 |
|  |  |  |  |
| **拖放材質** | CTRL+拖放 | ⌘+拖放 | 按下並按住此鍵，同時拖放材質（或智慧材質）到視窗中，只影響 3D 模型的特定部分。 |
|  |  |  |  |
| **操作員約束/吸附** | Shift | Shift | 在 3D 視圖中調整操作手（平移或旋轉）時的吸附變換。 在2D視圖中調整操作手時的約束比。 |
| **操作手鏡變換** | Ctrl | ⌘ | 鏡像操作手在 2D 視圖中圍繞其樞軸點的轉換。 |
