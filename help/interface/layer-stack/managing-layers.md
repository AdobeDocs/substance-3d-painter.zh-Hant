# 管理層級

以下是圖層堆疊內部可能的操作方式：

| *行動* | *示範* |
| --- | --- |
| 點擊並拖曳即可移動圖層。 移動圖層時，可以看到一條長條，指示該圖層將放置的位置：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>圖層</strong> 上方的條：圖層會被放置在該圖層之上</li><li data-preserve-html="true"><strong>兩層</strong> 之間的條：該層會被放在兩層之間</li><li data-preserve-html="true"><strong>圖層</strong> 下方的條：該圖層會放在圖層下方</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-above.gif"/></div> |
| **移動到資料夾** ：點擊並放置圖層，將滑鼠移到資料夾中放置 | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-folder.gif"/></div> |
| **多重選擇** ：可透過兩種不同方式進行：<ul data-preserve-html="true"><li data-preserve-html="true">按住並維持 Ctrl 或 Command 鍵</li><li data-preserve-html="true">同時按下 Shift 鍵，點擊第一層和最後一層</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-ctrlselect.gif"/></div><div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid1_items_grid-cell_position-par_image" src="../../assets/dragdrop-shiftselect.gif"/></div> |
| **圖層** 分組：可用以下動作之一建立資料夾，包含目前選取的圖層：<ul data-preserve-html="true"><li data-preserve-html="true">右鍵點擊 > 群組圖層</li><li data-preserve-html="true">按 Ctrl+G 或 Command + G</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/group-layer.gif"/></div> |
