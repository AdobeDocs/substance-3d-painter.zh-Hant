# 材質集

![](../../assets/texture-set.png)

Substance 3D Painter 每次在匯入的網格上找到材質 ID，都會自動建立新的貼圖集（[除非專案使用 UV Tile 工作流程](../../features/uv-tiles/uv-tiles.md)）。

每個材質 ID 預期會有獨特的 UV（或鏡像幾何的邏輯重疊）。

關於貼圖集&#x200B;**屬性與操作的更多細節**，請參見：

* [材質組合清單](texture-set-list.md)
* [材質集設定](texture-set-settings.md)
* [材質集重新指派](texture-set-reassignment.md)
