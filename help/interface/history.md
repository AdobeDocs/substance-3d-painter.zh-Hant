# 歷史記錄

![](../assets/history-list.png)\
歷史視窗列出目前已開啟專案中所有的行動與修改。

* 清單中的每個元素都可以點擊，回到該動作建立或套用時的專案狀態。
* 在不在清單最後一個元素時建立新動作，會抹除現有的未來動作，並以新的動作取代。
* 這些動作是專案的全域，因此在兩個不同材質集建立圖層會顯示在同一個清單中。

雖然所有資訊都儲存在專案中（以便重新繪製或重新貼圖），但如果專案關閉再重新開啟，歷史清單將無法存取。 歷史列表僅在本會期內提供。
