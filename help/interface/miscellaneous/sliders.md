# 滑桿

本頁說明如何在應用程式介面中使用滑桿。

| 動作 | 範例 | 說明 |
| --- | --- | --- |
| **阻力** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/drag-slider.gif"/></div> | 滑鼠滑鼠時點擊並拖曳即可更改數值。 |
| **精密阻力** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/precision-slider.gif"/></div> | 按下並長按鍵盤上的 Shift 鍵，點擊滑桿可增加拖曳距離。 這個快捷鍵允許在拖曳滑桿時更精確地調整滑桿。 |
| **跳躍** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/jump-slider.gif"/></div> | 點擊滑桿上的任意位置，可以跳到滑鼠位置下方的值。 |
| **上/下** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/up-down-sliders.gif"/></div> | 點擊滑桿鎖定焦點後，使用鍵盤上的上下方向鍵逐步增加或減少數值。 |
| **價值版** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r5-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/value-edit-slider.gif"/></div> | 點擊滑桿上方的文字欄位，透過鍵盤手動編輯其數值。 |
