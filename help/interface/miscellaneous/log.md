# 日誌

![](../../assets/log.png)

日誌是 Substance 3D Painter 與 [Plugins](../../features/plugins/plugins.md) 可以顯示狀態更新、追蹤進度、警告與錯誤的地方。

日誌分為兩個分頁。

* **General 標籤**&#x200B;會顯示與你的專案和場景相關的資訊，包括匯出細節。
* 資產標籤&#x200B;**會**&#x200B;顯示與&#x200B;**資產面板**&#x200B;相關的錯誤與日誌。
