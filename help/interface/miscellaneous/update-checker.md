# 更新檢查器

![](../../assets/update-cc.png)

你可以從 Creative Cloud Desktop 查詢 Substance 3D Painter 的更新。 進入應用程式標籤，看看已安裝的應用程式區塊。 **若有更新可供下載，應用程式名稱下會出現「可用** 更新」。

你可以打開 Painter 並使用 **「Help > Release Notes」**&#x200B;來取得目前版本的發行說明。
