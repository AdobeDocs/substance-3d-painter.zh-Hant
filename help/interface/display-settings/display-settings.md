# 顯示設定

![](../../assets/display-settings-2.png){width="320px"}

顯示設定&#x200B;**視窗會**&#x200B;重新組合環境、相機和視窗設定。這些設定是專案的全域設定，可能會影響視窗的外觀。

## 檢視模式

![](../../assets/viewmode.png)

檢視模式控制視窗的外觀。 下拉選單分為三個區塊：

| 章節 | 說明 |
| --- | --- |
| **照明** | 在視窗中顯示 3D 模型，並使用完整光照，若啟用則包含陰影。 |
| **單通道** | 也叫單人模式。 在視窗中只顯示特定的通道或材質，且不使用光照。 |
| **網格貼圖** | 在視窗中只顯示特定的烘焙材質網格，且不使用光照。 |

>[!NOTE]
>
> 也可以透過<b>視窗角落[](../../interface/viewport/viewport.md)的下拉選單</b>來切換視角模式。還有[快捷鍵](../settings/shortcuts.md)可以快速切換通道、網格貼圖，甚至回到材質模式。
