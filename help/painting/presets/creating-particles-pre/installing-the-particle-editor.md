# 安裝粒子編輯器

要建立和編輯粒子系統行為，必須使用 PopcornFX 編輯器。\
請從以下連結下載編輯器： [Mirror 1](http://downloads.popcornfx.com/updates/1.5.5.20787/PopcornFx-Editor_Setup_v1.5.5.20787.exe)、 [Mirror 2](https://www.dropbox.com/s/z1vwzvk2ywlug4p/PopcornFx-Editor_Setup_v1.5.5.20787.exe?dl=1)。

>[!NOTE]
>
> Painter 使用舊版編輯器，因為它需要特定版本的支援。 更多資訊請 [參考官方維基](https://wiki.popcornfx.com/)。
