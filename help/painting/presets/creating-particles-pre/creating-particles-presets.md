# 建立粒子預設

允許繪製粒子的粒子系統使用  **PopcornFX** ，該系統依賴 **.pkfx** 檔案來定義行為。

粒子筆刷由兩部分組成： **發射器** 與 **接收** 器，兩者同時儲存在預設中。 應用程式會載入發射器，並在塗裝時覆蓋碰撞事件以發射接收器。
