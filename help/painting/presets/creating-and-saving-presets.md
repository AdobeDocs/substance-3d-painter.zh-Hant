# 建立並儲存預設

用 [屬性視窗](../../interface/properties.md)調整筆刷參數，然後把筆刷設定存為預設，方便日後快速重用。

>[!NOTE]
>
> [裝備 Path 工具](../tool-list/path.md)後，屬性面板](../../interface/properties.md)中會出現[預設區塊，讓你能快速存取與路徑相關的預設。你也可以把路徑預設加入你的收藏。 在這裡了解更多管理你最喜愛 [路徑預設](../tool-list/path.md)的方法。

## 建立一個新的預設

![](../../assets/save-preset-1.png)

當工具屬性（繪圖層或繪圖效果）可用時，可以在屬性視窗中右鍵點擊來建立預設。

在屬性視窗中右鍵點擊，即可開啟包含以下選項的右鍵選單：

* <b>建立工具預設</b> ：將筆刷參數和所有所需資源的材質儲存在同一預設檔案中。
* <b>建立材質預設</b> ：只將材質屬性和材料資源儲存在預設檔案中。
* <b>建立筆刷預設</b> ：只將筆刷參數以及 alpha 和模板資源儲存在預設檔案中。

## 更新現有預設

![](../../assets/update-preset.png)

你可以根據屬性視窗中的當前值更新現有的預設。 在資產](../../interface/assets/assets.md)視窗中右鍵點擊該資產[，選擇「從目前工具更新」即可更新預設。
