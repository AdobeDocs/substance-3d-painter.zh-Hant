# 快速面罩

快速遮罩可以讓你遮罩不想要塗裝的網格部分。

* 按 **Y** 鍵切換到快速遮罩編輯模式，這樣可以繪製臨時遮罩。
* 再按 **一次 U** 鍵切回之前的工具，然後在遮罩上塗色。
* 按 **Y** 鍵可以重置或停用遮罩。
* 在快速遮罩編輯模式下按 **I** 鍵可以反轉遮罩。
