# 投射

![](../../assets/image2015-3-19-17-56-54.png){width="50px"}

投影是一種工具，允許透過投影在螢幕/視窗空間中來繪製材質。 它與模板共享類似的控制方式。

可透過按下 **快捷鍵 S** 來編輯投影變換：

* 用 **S + 左鍵點擊** 來旋轉模板。
* 用 **S + 左鍵點擊 + SHIFT** 鍵來吸附/限制模板的旋轉。
* 用 **S + 右鍵點擊** 來放大/縮放模板。
* 使用 **S + 中鍵** 點擊來翻譯模板。
