# 填土路徑

![](../../assets/banner_filled_path.jpg)

填充路徑工具是一種路徑工具，允許在3D模型表面建立填充均勻顏色的形狀。

![](../../assets/filled_path_across_gaps.png)

<b>填充路徑</b>工具可從路徑工具選單中存取：

![](../../assets/filled_path_menu.png)

## 設定

路徑填充設定如下：

| 背景設定 | 說明 |
| --- | --- |
| 不透明度 | 控制填充形狀的最終不透明度。 |
