# 進階水道繪畫

部分著色器預設通道可繪製成進階或複雜效果。 例如，將高度資訊轉換成法線貼圖。

目前可用的頻道：

* [環境遮蔽繪畫](ambient-occlusion-painting.md)
* [流程圖繪畫](flow-map-painting.md)
* [高度圖繪製](height-map-painting.md)
* [法線貼圖繪製](normal-map-painting.md)
