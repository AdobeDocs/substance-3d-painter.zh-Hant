# 版本 2017.4

**Substance Painter 2017.4** 新增了工作流程功能，透過 **圖層實例** 化，讓專案內不同材質集的圖層能輕鬆同步。

上映日期： *2017年11月23日*

## 主要特色

### 層實例化

![](../../assets/instancing.jpg)

**圖層實例**&#x200B;化是一種新系統，允許在其他圖層與紋理集&#x200B;**間保持**&#x200B;同步&#x200B;**的圖層**&#x200B;參數&#x200B;**&#x200B;**。建立圖層實例時，原始圖層會成為 **來源** ，除非連結斷開，否則實例會 **持續更新** 。 實例化圖層是&#x200B;**&#x200B;**&#x200B;快速&#x200B;**點擊素材貼圖**&#x200B;的好方法，省去來回更新圖層。要輕鬆貼圖資產，只要 **在其他材質集間實例化一個資料夾** ，放入智慧材質或其他圖層，它就會立即複製 **到各處** 。

建立實例有兩種方式：

* 複製圖層後，選擇「**貼上為實例**」（或使用快捷鍵 CTRL+SHIFT+V）
* 選取一層後，選擇&#x200B;**「**&#x200B;跨材質集實例化」（或使用快捷鍵 CTRL+SHIFT+D）

>[!NOTE]
>
> 層實例化有一些限制：
> 
> * 任何繪畫動作只會存在於來源圖層，實例圖層不會複製筆觸。
> * Anchor 的參考必須在實例的同一層級有錨點，錨點不能在實例資料夾之外，否則會被破壞。
> * 如果一個智慧材質是與實例圖層一起儲存的，來源圖層必須在智慧材質資料夾中，否則實例連結會中斷。
> * 根據層堆疊的設定，實例化圖層可能會產生循環，但這不支援，會破壞實例結果。 要麼刪除，要麼移動實例來修正。

更多細節與範例，請參閱專門頁面： [Layer instancing](../../interface/layer-stack/layer-instancing.md)

### 支援 Unreal Engine 4 的 DCC Live-Link

![](../../assets/livelink.jpg)

我們&#x200B;**原本的 live link 外掛**&#x200B;測試版現在已經整合&#x200B;**&#x200B;**&#x200B;進 Substance Painter。我們藉此機會支援了 Unreal Engine 4，現在它能自動將專案結果放入引擎。

要將應用程式 **連接到 Unreal Engine 4** （至少需要版本 **4.18** ），請在此下載 Substance 插件： <https://www.unrealengine.com/marketplace/substance-plugin>

### 新書架內容

![](../../assets/materials-1.jpg)

我們新增 **了 20 種程序生成的素材** ，也新增 **了 40 張新的垃圾搖滾地圖** （其中有些是程序化的）。 新材料可以在書架&#x200B;**的**「**材料**」區找到，例如6種新金屬、8種新塑膠、幾種布料和2種新木質表面。新的垃圾搖滾地圖可以直接在書架&#x200B;**的**「**垃圾搖滾**」區找到。

![](../../assets/grunges-1.jpg)

非常感謝 Clément Feuillet 和 Nicolas Longchamps 允許我們為這個新版本授權他們的內容。

### SketchFab 匯出改進

![](../../assets/sketchfab.jpg)

我們更新了 Sketchfab 匯出功能，並新增了將專案發佈為草稿，甚至更新已上傳專案的功能。 這應該會讓專案迭代變得更容易。

### 性能改進

我們持續推動績效改進工作。 在這個新版本中，我們重新設計了許多 OpenGL 的視窗渲染，應該能帶來不錯的速度提升。 我們也改進了筆觸的計算方式，因此在記憶體中需要的紋理計算量應該大幅減少。 整體來說，這樣會帶來更快的效果和更好的上色感覺。

## 發行說明

### 2017.4.2

（2018年1月24日發行）

**補充：**

* [匯出]取得匯出狀態及步驟進度
* [匯出]允許取消匯出
* [匯出]將貼圖匯出到 Sketchfab 而不損失法線貼圖品質
* [匯出]以 glTF 二進位格式（glb）匯出
* [匯出]在匯出視窗的設定標籤中允許調整欄位大小
* [著色器]新增著色器 API 的變更日誌
* [腳本操作]匯出貼圖時加入前後回調函數
* [Iray]升級至 SDK 2017.1（支援 Volta GPU）

**&#x200B;**&#x200B;修正：**&#x200B;**

* 在主視窗顯示前退出應用程式時會當機
* [MAC]載入 IRAY 灰階地圖時當機
* [MAC]新的 High Sierra OS 顯示記憶體偵測不正確
* [外掛]從 Substance Source 下載資產已無法使用
* [腳本]錯誤的最小外掛版本偵測
* [匯出]匯出材質後無法儲存匯出預設
* [實例化]在沒有額外貼圖的貼圖集中實例化的產生器出現問題
* [視窗]抖動在4k以上解析度下無法運作
* [視窗] 2D View 材質顯示被雜訊覆蓋
* [書架]改善書架預設的載入時間
* [引擎]在色彩選擇下繪製時，混合不正確

### 2017.4.1

（2017年12月15日發行）

**補充：**

* [腳本操作]透過腳本 API 匯出網格
* [匯入]關閉不支援的網狀檔案格式匯入（僅允許 obj、fbx、dae、ply）
* [日誌]請更精確地指出日誌檔中的TDR問題

**修正：**

* 如果應用程式在資源爬取完成前關閉，就會當機
* 使用 Smudge/Clone 工具開啟專案時會當機
* 在檢視器設定中還原著色器變更後，使用重做時會當機
* [引擎]Painter 2017.2 與 2017.4 之間的貼圖有所不同
* [視窗]從實例中選取 ID 映射會取樣錯誤的顏色
* [匯出]匯出無效法線或遮蔽材質時會當機
* [匯出]PSD 檔案在 Photoshop CS6 開啟時群組會被鎖定
* [外掛]Photoshop 外掛會忽略通道選擇，並且總是匯出所有內容
* [圖層]在複製/貼上於貼圖集時，錨點會斷裂
* [層]有些錨點的參考若被破壞，將無法恢復
* [著色器] PBR塗層次級粗糙度參數被破壞
* [Steam]版本檢查器彈窗在遊戲啟動時不應該顯示

**已知問題：**

* [AMD 版]嘗試在網格上繪製時會當機/凍結。 可以透過更新顯示卡驅動程式來解決。

* [實例化]允許跨層實例化參數

* [實例化]不允許 Anchor 的參考資料來自實例資料夾外
* [使用者介面]將復原堆疊移入名為「歷史」的獨立視窗
* [插件]整合 DCC 即時連結插件
* [引擎]用稀疏的繪畫提升繪畫表現
* [匯出]為 Sketchfab 匯出器新增草稿與重新匯出選項
* [書架]新增字型物質的「翻轉」控制
* [書架]新增20個程序性材料
* [書架]新增 40 張 grunge 地圖（點陣圖與程序生成）
