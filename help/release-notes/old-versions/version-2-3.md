# 版本 2.3

**Substance Painter 2.3** 改進了腳本 API，以釋出首個官方外掛：一個包含完整圖層堆疊的 Photoshop 匯出工具。

上映日期： *2016年9月15日*

## 主要特色

### 新的 Photoshop 匯出外掛

![](../../assets/ps-230.jpg)

這次釋出我們專注於在腳本 API 中加入新的可能性，以實作 **Photoshop** 的進階匯出器。 要存取這個新匯出，只要點擊主工具列中可用的 Photoshop 圖示（如果外掛已啟用，預設情況下）。 這個外掛允許匯出貼圖集中可用的完整圖層堆疊，並在 PSD 檔案中建立類似的結構。 此功能 **需要在電腦上安裝** Photoshop 才能產生 PSD 檔案。

透過插件選單中的配置按鈕，有幾個選項可供選擇：

## 發行說明

### 2.3.1

（2016年10月7日發行）

**新增：**

* [外掛][Photoshop]允許指定要匯出哪些材質/堆疊/通道
* [腳本操作]函式名稱存在一些不一致之處

**已修正：**

* [匯出]在自訂匯出預設中可以捨棄 Alpha
* [匯出]Alpha 在 sRGB 頻道的伽瑪轉換錯誤
* [匯出]非方形文件匯出為平方
* [匯出]如果缺少一張地圖，就無法匯出額外的地圖
* [Iray]有些參數（例如發射強度）沒有影響
* [NVIDIA]NVIDIA Quadro K2200/GTX 750/760 啟動時當機
* [AMD]縮圖與預覽的顏色組不正確
* [AMD]新檔案與檔案開啟時當機與驅動程式故障
* [日誌]「軟體版本」在日誌檔中缺少

### 2.3.0

（2016年9月15日發行）

**新增：**

* [外掛]新的「匯出到 Photoshop」外掛（匯出完整圖層堆疊）
* [匯出]允許指定填充的寬度（以像素或無限為單位）
* [匯出]允許設定 UV 外的背景類型
* [書架]新材質分層著色器，可混合 10 種材質
* [書架]新的黏土著色器，可以用高度/法線通道查看細節
* [書架]新的烘焙光影濾鏡，帶有環境輸入
* [書架]更新了一些遮罩產生器，加入了非平方變換
* [視窗]在單人模式下新增合成法線貼圖（法線+高度+烘焙）
* [腳本操作]允許匯出更多地圖
* [腳本]允許查詢可用地圖每個貼圖集
* [腳本操作]允許取得通道格式
* [腳本操作]在烘焙文件中加入範例
* [腳本操作]允許查詢圖層的可見性
* [腳本操作]允許查詢圖層的混合模式與透明度
* [腳本]允許匯出已轉換的地圖（最終法線貼圖、混合 AO 等）
* [內容]閱讀並連結自訂用法
* [快捷鍵]新增修飾鍵（SHIFT）可逆向單人模式
* [匯出]更新預設匯出預設以停用 alpha
* [使用者介面]縮圖現在只有在引擎尚未取得時才會計算
* [使用者介面]當縮圖正在計算時，顯示提及

**已修正：**

* 打開舊專案時會當機
* 當機時材質通道快取損壞
* 使用 Material Layering 工作流程混合超過 4 種材質時會當機
* [使用者介面]如果工具列被隱藏，工具捷徑就無法使用。
* [使用者介面]Iray 工具列在檢視選單中標示為「未命名」
* [使用者介面]插件工具列在檢視選單中命名為「Untilted」
* [烘焙師]編輯烘焙設定時按下 Enter 鍵會啟動烘焙過程
* [貝克]某些參數的範圍不正確
* [匯入]由於數字過大，無法匯入 OBJ 網格
* [匯入]有些 OBJ 檔案匯入時子物件過多
* [匯出] 通道背景在匯出時以黑色填補，而非預設顏色
* [工具]如果視野太低，粒子就無法正常運作
* [工具]遮罩在子堆疊中，畫筆預覽顏色不正確
* [視窗]當刷子進入2D視角的空地時，會變得巨大無比
* [視窗]繪製時的空白筆刷預覽法線貼圖
* [腳本操作]文件錯誤：將「ao」列為「ambientocclusion」
* [腳本]以子程序（）啟動的程序在關閉 Painter 時會被終止
* [書架]烘焙光影濾鏡使用錯誤的AO輸入
* [MacOS]已移除消防栓專案（不相容）
* 預設專案在載入 \*.spt 檔案時會開啟（而非 \*.spp）。
