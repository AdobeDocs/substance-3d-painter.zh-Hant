# 2017.1 版本

Substance Painter 在新 Substance 產品推出後更改了版本編號。 更多詳情請參考： <https://www.allegorithmic.com/welcome-to-substance>\
在這個新版本中，我們希望專注於內容，提供一個新插件，讓玩家能瀏覽 Substance Source 並直接匯入材料到書架。 我們也加入了許多新素材，擴展你的創意可能性。

上映日期： *2017年6月20日*

## 主要特色

### 新插件：Substance Source

![](../../assets/source-optim.gif)

有了這個新外掛，現在可以 **直接瀏覽** 我們名為 **Substance Source** 的材料資料庫，並直接下載 **到書架**&#x200B;上，隨時可用，並隨時投入你的專案。\
要開啟 Substance Source，只需點擊應用程式主工具列&#x200B;**中的 Substance Source 標誌**&#x200B;即可。這樣應該會開啟一個新視窗，讓你瀏覽圖書館。

![](../../assets/source-overview.jpg){width="650px"}

### 新內容：Alpha、程序劇、篩選器等

![](../../assets/new-alphas-gif.gif)

在這個新版本中，我們將新增 **超過 300 個資產**。 我們在 alpha 版中加入&#x200B;**了科幻**、**幾何**&#x200B;**、中世紀**&#x200B;甚至&#x200B;**凱爾特**&#x200B;主題的內容。裡面還有很多 **新筆刷** 和 **掃描的手印/指紋**。 我們也提供一些實用的新濾鏡，例如 **MatFX Detail Edge Wear**，能直接&#x200B;**根據網格上正常繪製的資訊**&#x200B;產生&#x200B;**刮痕**。

以下是新內容列表：

* **4 種新字型** （日文、簡體中文、打字機、分段）
* **230 個新 Alpha** （圖案與掃描影像混合）
* **50 款新程序劇** （多為中世紀及當代服裝的布料圖案）
* **2 張新環境地圖** （Mondarrain 與 Villa Nova 街）
* **9 新濾鏡** （MatFX Detail 邊緣磨損、夾具、HBAO 等）

![](../../assets/alpha-content.jpg)![](../../assets/alpha-demo-image.jpg)

我們也更新了一些現有資產，使其運作更順暢，例如 **預設環境地圖** ，現在看起來 **不再那麼黃 ：**

![](../../assets/new-env-map.gif)
