# 版本 2017.3

**Substance Painter 2017.3** 專注於支援 Adobe Project Felix **及開放格式** glTF **的進階匯出預設。**&#x200B;這次新版本也著重於使用者體驗，改進介面並加入自動存檔外掛。

上映日期： *2017年9月28日*

## 主要特色

### Adobe Standard Material 匯出預設

![](../../assets/adobe-dimension-meetmat.jpg)

本版本新增的匯出器之一是支援 Adobe Standard Material，該資料可與 Adobe Dimension（前稱 Adobe Project Felix）一起使用。 我們允許你一鍵匯出場景網格及其材質，匯入 Project Felix。 要存取它，只需在匯出貼圖視窗中選擇「**Adobe Standard Material**」。 更多資訊請參見： [http://www.adobe.com/tw/products/dimension.html](https://www.adobe.com/tw/products/dimension.html)

你也可以看看我們關於這件事的部落格文章： <https://www.allegorithmic.com/blog/new-dimension-substance-ecosystem>

### glTF 2.0 匯出預設

![](../../assets/gltf-export.jpg)

我們也新增了對 **glTF** 檔案格式的支援，並匯出 **場景網格** 和 **PBR 材質** （金屬/粗糙度）。 要進入它，只要在匯出貼圖視窗中選擇「**glTF PBR Metal Roughness**」。 **glTF** 是一種由 Khronos 團隊主導的開源檔案格式。 你可以在 Windows 10 內&#x200B;**查看你的 glTF 檔案，或直接使用 WebGL 瀏覽器，例如[** Babylon](http://sandbox.babylonjs.com/)**。**

欲了解更多資訊，請參閱： <https://github.com/KhronosGroup/glTF>

### 自動儲存外掛

![](../../assets/autosave-details.png)

在這個版本中，我們還加入了一個新的外掛程式，可以 **為目前已開啟的專案建立備份** 。 它會在目前已開啟的專案側邊建立一個備份檔案。\
因此，我們在檔案選單中新增了「**另存為複製**&#x200B;品」的項目。 **自動存檔**&#x200B;可以透過關閉插件本身來停止，設定&#x200B;**&#x200B;**&#x200B;則可透過設定面板&#x200B;**進入**。當警告時間延遲到達時， **主工具列按鈕下方會出現進度條** ，方便你在需要時暫停幾分鐘（如果你想在備份前完成某件事很方便）。

如果已經建立備份但專案尚未被儲存（也就是 Untilted），備份會儲存在 **Documents/Allegorithmic/Substance Painter/autosave** 資料夾裡。 否則，備份會放在專案旁邊（除非路徑被設定面板覆蓋）。

### 改良的梯度濾波器

![](../../assets/gradient-rust.jpg)

**漸層濾鏡**&#x200B;已經完全重新設計。它的運作方式更接近 **Substance Designer** 裡&#x200B;**的漸層貼圖**&#x200B;節點。現在支援最多 **10 種不同顏色**，並能指定&#x200B;**顏色在漸層&#x200B;**&#x200B;**中**&#x200B;的位置，開啟許多新的可能性。這不僅能創造更&#x200B;**進階的色彩圖案**，也能&#x200B;**重新映射高度貼圖**&#x200B;並創造&#x200B;**新形狀**。

主要滑桿（色彩量）定義用來產生漸變的總色彩數量。 下方的按鈕定義了色彩混合模式（sRGB 或線性）。 如果你想讓顏色之間有適當的融合，這點非常重要。 例如，將純紅色和純綠色混合，應該能在中間產生漂亮的黃色調。 如果按鈕被禁用，情況就不會了（會顯示深棕色）。 在重新映射高度或其他灰階通道時，應該關閉這個按鈕，以避免進行伽瑪轉換。

頂部的按鈕可以將濾波器的結果替換成漸層，讓 2D 視圖中呈現漸變。

![](../../assets/gradient-height-demo.jpg)

### 介面與行為改進

![](../../assets/tabs-top.png)

在此版本中， **應用程式不同底座的分頁** 現在 **位於各自視窗的頂部，而非底部** 。 此選擇旨在提升介面的可讀性，同時也讓介面與其他應用程式更為一致。 接著在分頁標題旁加入&#x200B;**了小十字**，方便&#x200B;**關閉。**&#x200B;**也可以在分頁上右鍵點擊**，開啟&#x200B;**一個情境選單**（可以關閉或移除視窗）。解除視窗底座的捷徑是直接拖放視窗外的分頁。

現在也可以透過&#x200B;**從檔案總管拖放**&#x200B;專案到視窗&#x200B;**來開啟**。這方法也適用於&#x200B;**網格**&#x200B;檔案：在空視窗&#x200B;**拖放網格檔案**&#x200B;會開啟&#x200B;**新的專案視窗**，但拖&#x200B;**放已開啟的專案**&#x200B;會開啟&#x200B;**專案設定對話框**，方便快速&#x200B;**更新網格**。

**注意** ：如果你有拖放功能，請務必[查看我們相關](../../technical-support/technical-issues/miscellaneous-issues/impossible-to-drag-and-drop-files-into-the-shelf.md)常見問題。

### 性能改進

這個版本的 Substance Painter 也包含了一項全新且強大的效能改進，特別是在我們管理 GPU 記憶體（VRam）方面。 均勻的顏色（如填充層）現在被壓縮成較小的貼圖，加速它們在主記憶體與 GPU 記憶體間的傳輸，同時也減少記憶體佔用與計算時間。 這在開啟大型專案或 GPU 記憶體極限時特別明顯。
