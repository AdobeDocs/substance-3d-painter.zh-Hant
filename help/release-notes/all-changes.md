# 所有變動

>[!NOTE]
>
> 欲查看可能影響 Painter 的已知問題，請參閱 [專門的文件頁面](known-issues.md)。

## 版本 12

### 12.1.3

上映日期： **2026/08/26**

摘要： **小規模發行**

**補充：**

* 更新 Substance 引擎至 9.4.6 版本

**修正：**

* [灰階選拔] 器 換工具後拾取器會保持開啟
* [傾斜烘焙] 在塗裝和復原時，偏差校正會斷裂

摘要： **小規模發行**
