# 使用者資料

本頁描述可新增於 Substance 圖中的自訂屬性（使用者資料），以執行特定行為。\
使用者資料設定通常套用在圖形的輸入或輸出節點上，以指示應用程式應如何解讀它們。 這讓圖形輸入能以特定方式呈現，並在已知情境下套用效果（例如請求特定色彩空間），或在應用程式之後需要額外轉換時，指示輸出的產生方式。

* 使用資料設定定義為 **key = value**
* 多個設定以分號分隔  **（ ;**  )

## 色彩空間

**色彩空間**&#x200B;設定可用來請求具有特定色彩空間的 Substance 圖輸入，或定義以特定方式配置的輸出。例如，指定法線貼圖輸出的格式。

語法範例： **colorspace =$working**

情境概述：

* **顏色按鈕**：Substance 圖屬性中的顏色按鈕小工具。
* **圖輸入/輸出**：連接至通道（例如：BaseColor）的圖形輸入或輸出節點。
* **影像輸入**：圖形的通用輸入，與特定通道無關。

>[!NOTE]
>
> 隨著色彩管理的引入，與色彩空間設定相關的幾項行為有所改變：
> 
> * 下表首先列出版本 8.1 之前相容的色彩空間設定。 第二部分僅限於 8.1 版本及以後版本。
> * 關於色彩空間設定可使用的情境，只有從 8.1 版本開始，顏色按鈕才能定義色彩空間。 在先前版本中，它們被假設存在於顯示空間（sRGB）。
> 
> **snorm** 和 **unorm** 色彩空間/轉換不應該和 GPU 材質格式混用，因為它們的用途不同。

| 色彩空間 | 上下文可用性 | 說明 |
| --- | --- | --- |
| **自動** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 預設。 應用程式會根據輸入節點的屬性及插入的影像，決定要執行的色彩空間轉換。 |
| **線性** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 標準 sRGB IEC 61966-2-1：1999 色彩空間，採用線性伽瑪/色調曲線。 僅在 **Legacy** 色彩管理模式中提供。 |
| **SRGB** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 標準 sRGB IEC 61966-2-1：1999 色彩空間。 僅在 **Legacy** 色彩管理模式中提供。 |
| **穿越** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 已棄用。 在 Legacy 色彩管理模式下&#x200B;**被解讀為**&#x200B;線性&#x200B;**，使用 OCIO/ACE 則是 RAW**。應該改成 **生食** 。 |
| **標準** | 圖形輸入/輸出影像輸入 | 簽名歸類。 請求輸入影像在 [0， 1] 範圍內。 對於 8 位元輸入影像，這表示中間值是 127。 對於浮動影像輸入，中間位置為 0.5，且不進行任何夾位。 |
| **normalxyzright** | 圖形輸入/輸出影像輸入 | OpenGL 法線貼圖格式。 |
| **normalxyzleft** | 圖形輸入/輸出影像輸入 | DirectX 法線貼圖格式。 |
|  |  |  |
| **UNORM** | 圖形輸入/輸出影像輸入 | 沒有距離/夾位的浮動輸入。 |
| **資料** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 無符號正規化或浮動。 非顏色資訊。 |
| **原始版** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 使用此設定時不會套用顏色轉換。 |
| **$standardsrgb** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 標準 sRGB IEC 61966-2-1：1999 色彩空間。 |
| **$working** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 工作色彩空間，取決於色彩管理設定。 將與非色彩管理通道及單通道（模板、alpha、遮罩）的資料完全相同 |
| **$raw** | 顏色按鈕 圖形輸入/輸出 影像輸入 | Raw **的**&#x200B;別名。 |
| **$auto** | 顏色按鈕 圖形輸入/輸出 影像輸入 | 汽車的別名&#x200B;**&#x200B;**。 |

## Alpha 模式

**&#x200B;**&#x200B;alpha 設定可用來指定顏色輸入或輸出（RGBA）的 alpha 如何組合。

語法範例： **alpha=預乘**

| 背景設定 | 說明 |
| --- | --- |
| 垂直 | 請求或定義阿爾法為異性戀。 |
| 預乘法 | 請求或定義 alpha 為預先乘法。 |
| 沒有 | 直通，直接使用給定的 alpha 版本。 |

>[!NOTE]
>
> 通道 **不透明度** 預設被視為 **直線** 。

## 影像輸入的預設顏色

Substance 圖影像輸入的預設顏色為黑色，alpha 設為 0。 **defaultcolor** 設定允許在圖形的影像輸入為空時定義不同的值

可用浮動值（範圍 [0， 1]）或整數值（範圍 [0， 255]）來指定顏色。 每個成分值以逗號分隔，而浮點值則以點作為十進位分隔符。 若浮動不指向，則視為整數。

語法範例：

* **defaultcolor=（1.0,0.5,0.0）**
* **預設顏色=（0,128,255）**

## 影像輸入填充

根據 Substance 圖的預設影像輸入，沒有填充，UV 島外區域通常會以均勻的顏色填充，以提升效能。 填充設定可以用來請求無限膨脹，例如濾波器避免產生接縫。

語法範例： **p**&#x200B;**adding=extend**

## 預設關閉輸出

當將物質加入槽位（例如填充層工具的材料槽）時，可以透過元資料文字欄位指定不啟用特定通道：

* 在特定輸出節點（如材料）上 ：  **disable=（true）**
* 在一般輸出節點（如濾波器）上 ：  **disable=（高度、擴散、鏡面）**

載入物質時，使用者介面不會啟用此通道，因此在層堆疊中不會產生影響。 使用者仍然可以啟用該頻道。

## 指定輸出為共用遮罩/alpha

Substance 圖的輸出可共用 alpha 通道/遮罩於其他輸出上。

有兩種方式可以做到：

* 建立一個輸出節點，並標識 **為通道_Alpha**
* 或在特定輸出節點新增以下使用者資料：  **IsChannelsAlpha=true**

以下條件可能適用：

* 如果存在帶有識別 **碼通道_Alpha** 的輸出節點，而其他輸出沒有使用者資料，該節點將被用作通道遮罩。
* 如果輸出包含使用者資料，只要沒有 **通道或節點存在_Alpha** 它就會被用作通道的遮罩。
* 如果同時&#x200B;**存在通道節點與包含使用者資料的節點_Alpha則**&#x200B;會優先使用通道_Alpha **&#x200B;**&#x200B;輸出節點。
* 若多個節點擁有使用者資料，應用程式會先找到的節點作為通道遮罩。 輸出的出現順序並不保證與 Substance 圖所定義的相同。

>[!NOTE]
>
> 此設定僅適用於材質 **模式**&#x200B;中使用的物質圖。 這不適用於濾波器、發電機等。

## 設定材質輸出的預設混合模式

當將材質從架子拖放到視口或圖層堆疊時，可以定義 Substance 圖中特定輸出的混合模式。

* 在特定輸出節點：  **blendingmode = normal（混合模式）= 正常**
