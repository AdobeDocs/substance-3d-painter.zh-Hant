# 網格地圖

若要在圖層新增效果時自動連接網格貼圖（烘焙貼圖），必須遵循特定的命名慣例。

>[!NOTE]
>
> 在輸入節點中可以使用 **使用量** 或 **識別碼** （使用權優先權）。

以下是每個網格貼圖的命名慣例：

| 網格貼圖 | 使用情況 | 識別碼 |
| --- | --- | --- |
| *環境遮蔽* | **ambientOcclusionBase** | **環境音樂_occlusion** |
| *身分證* | **身分證** | **身分證** |
| *曲率* | **曲率** | **曲率** |
| *正常* | **normalBase** | **正常_base** |
| *世界空間法線* | **正常世界** | **世界\_space\_normals** |
| *職位* | **職位** | **職位** |
| *厚度* | **厚度** | **厚度** |
| *高度* | **高度基底** | **身高_base** |
| *彎曲法線* | **彎法線基礎** | **彎_normals_base** |
| *不透明度* | **不透明度基地** | **不透明度_base** |
