# 透過拖放方式新增資源

資源匯入可透過將檔案拖放至介面的不同區域來完成。

## 匯入資產視窗

要將資源匯入 Painter，只需拖曳到資產視窗即可。

這會開啟 Improt 資源視窗，讓玩家可以控制資源的放置位置（在專案內、磁碟上跨專案重複使用，或暫時在工作階段中使用）。 此視窗也允許正確配置資源使用，因為有時某些檔案格式會不明確。

![GIF示範如何將資源拖放到資產視窗](../../assets/import_dragdrop_assets_window.gif)

### 匯入視窗

要將材質匯入並直接套用到你的專案中，只要拖曳到視窗中即可。 拖曳檔案時，應該會高滑網格，指示該網格會套用到專案的哪個部分。

![Gid 顯示將資源拖放到視窗中](../../assets/import_dragdrop_material_viewport.gif)

也可以透過拖放 SVG 檔案到視窗中匯入。 這樣做會產生一個包含扭曲投影模式和 Graphic 轉材質</b>的全新<b>圖層，方便製作貼紙。

![Gid 顯示將資源拖放到視窗中](../../assets/import_dragdrop_material_svg.gif)

### 匯入資源槽

將檔案拖放到介面中的資源槽，例如填充層內的通道，會匯入資源並自動套用。
