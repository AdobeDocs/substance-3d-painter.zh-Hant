# 烘焙模式

**烘焙模式** 提供你所需的所有工具和參數，讓你能做出高品質的烘焙。

要進入 **烘焙模式**，請點擊視窗右上角的（烘焙中的）可頌按鈕。 或者，使用 [快捷鍵&#x200B;](../interface/settings/shortcuts.md)**F8**，或選擇 **模式>烘焙網格貼圖**

![](../assets/baking/mode_select_buttons.png)

烘焙模式會改變介面佈局，並提供專門用於烘焙網格貼圖的不同面板。

## 介面

烘焙模式介面預設分為 [**視窗**](../interface/viewport/viewport.md) 與面板區域。

### 視框

[**視窗**](../interface/viewport/viewport.md)&#x200B;的行為與&#x200B;**繪畫模式**&#x200B;相同。你可以用相同的控制方式來導航，並用 **頻道下拉選單** 來更改顯示的頻道。

**烘焙模式的視窗**&#x200B;與&#x200B;**繪畫模式**&#x200B;有兩個不同之處：

* 在視窗左上角，你可以找到 [**烘焙視覺化設定面板**](baking-visualization-settings.md)。
* 在視窗底部，你可以找到按鈕來 **烘焙** 目前選取的網格貼圖，或回到 **繪製模式**。

### 烘焙模式面板

烘焙模式有四個專屬面板：

* [**網格貼圖烘焙器**](../interface/baking-panels/mesh-map-bakers.md)：選擇哪些網格貼圖已經烘焙。
* [**常見設定**](../interface/baking-panels/common-mesh-map-settings.md)：調整所有網格貼圖共用的烘焙設定。
* [**網格貼圖設定面板**](../interface/baking-panels/mesh-map-settings.md)：調整所選網格貼圖的烘焙設定。
* [**烘焙日誌**](../interface/baking-panels/baking-log.md)：查看烘焙結果並診斷問題。

>
> 請參閱&#x200B;[**網格貼圖設定**](mesh-map-settings.md)，了解常見設定&#x200B;**與**&#x200B;網格貼圖設定面板&#x200B;**中的完整**&#x200B;選項列表。
