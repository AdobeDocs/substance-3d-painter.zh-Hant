# 網格貼圖設定

<b>網格貼圖設定面板</b> 在烘焙模式下有，並有控制功能可以讓你的網格準備好烘焙。 要調整特定地圖的網格貼圖設定，請在 <b>Mesh map bakers 面板</b>中選擇該貼圖。 每個網格地圖都可以有不同的設定。 <b>所有網格地圖共用的共通設定</b>集合可在網格地圖烘焙面板頂部取得。

任何跨網格貼圖共享的設定會顯示在共用設定頁面，而非每個網格貼圖。

## 常見設定

Common Settings 頁面包含影響所有網格貼圖烘焙方式的控制項。

### 輸出設定

| 背景設定 | 功能 |
| --- | --- |
| 輸出大小 | 定義生成網格貼圖的 X 和 Y 解析度。 點擊鎖定鍵即可允許非平方解析度。 |
| 膨脹寬度 | 調整烘焙資訊超出紫外線島嶼邊界的範圍。 |
| 施加擴散 | 啟用此框對產生資訊的邊緣施加擴散。 |

### 高多邊形參數

| 背景設定 | 功能 |
| --- | --- |
| 用低多邊形網格當高多邊形網格 | 啟用此設定，根據你的專案網格烘焙貼圖。 |
| 高解析度網格 | 在你的專案中加入高多邊形網格，從高多邊形網格製作到低多邊形網格上。 可以匯入多個網格。 |
| 籠子 | 確定烘焙籠是如何產生的。<ul data-preserve-html="true"> <li data-preserve-html="true">基於距離：將頂點從網格膨脹到均勻的距離，形成籠狀結構。</li> <li data-preserve-html="true">自動（實驗）：Painter 會分析你的網格並自動生成籠子，盡量讓籠子靠近表面而不產生交叉點，以達到最佳效果。</li> <li data-preserve-html="true">自訂檔案：匯入你已建立的檔案作為籠子使用。 請注意，匯入的檔案頂點數必須與基礎網格相同，才能正常運作。</li> </ul> |
| 忽略背面 | 切換烘焙時是否忽略背面。 這有助於減少雜訊，但也可能在某些邊緣情況下造成錯誤。 |
| 比賽 | 改變烘焙師在烘焙時判斷是否包含物品的方式：<ul data-preserve-html="true"> <li data-preserve-html="true">一定要：包含所有在烘焙時被擊中籠子內的高多邊形網格。</li> <li data-preserve-html="true">依照網格名稱：每個籠子只烘焙帶有對應網格後綴的網格。</li> </ul> |
| 低多邊形網格後綴 | 使用「Match By mesh」名稱時，請使用此後綴來定義低多邊形網格。 |
| 高多邊形網格後綴 | 使用「Match By 網格名稱」時，請使用此後綴定義高多邊形網格，並與相應的低多邊形網格匹配。 |
| 抗鋸齒 | 調整生成地圖中的抗鋸齒量。 |

#### 偏斜修正

| 背景設定 | 說明 |
| --- | --- |
| **油漆偏斜修正** | 進入偏斜修正繪圖模式。 |
| **邊緣保護** | 切換邊緣保護以遮蔽接近硬邊的塗裝偏斜修正值。 |
| **邊距** | 控制邊緣保護從硬邊延伸到的距離 |
| **邊緣對比** | 控制邊緣保護層從全保護到無保護的銳利過渡。 |

## ID 映射設定

| 背景設定 | 功能 |
| --- | --- |
| 色彩來源 | 改變 ID 貼圖烘焙顏色的判定方式：<ul data-preserve-html="true"> <li data-preserve-html="true">頂點顏色</li> <li data-preserve-html="true">材質顏色</li> <li data-preserve-html="true">檔案識別碼</li> <li data-preserve-html="true">網格識別碼/多元組</li> </ul> |
| 色彩產生器 | 使用檔案 ID 或 Mesh ID/多胞組作為色彩來源時，請確定顏色的產生方式：<ul data-preserve-html="true"> <li data-preserve-html="true">隨機</li> <li data-preserve-html="true">色相偏移</li> <li data-preserve-html="true">灰階</li> </ul> |

## 環境遮蔽地圖設定

| 背景設定 | 功能 |
| --- | --- |
| 次級射線 | 改變次要射線的數量。 更多的光線可以產生更好的結果，但代價是處理時間會增加。 |
| 最小奧克魯德距離 | 調整光線通過的最小距離，以達到高多邊形幾何體並影響產生的 AO 貼圖。 |
| 最大遮蔽距離 | 超出此距離且未觸及高多邊形網格的光線被視為不被遮蔽，不會影響 AO 貼圖。 |
| 相對於包圍盒 | 勾選此框後，其他與距離相關的設定會根據專案網格的邊界框來設定。 距離 1 等於包圍盒的大小。 |
| 擴散角 | 調整產生光線的角度範圍。 較高的展出角度使表面更容易被非垂直於表面的幾何形狀遮蔽。 |
| 分布 | 選擇光線的分布方式。 |
| 忽略背面 | 更改是否將背面視為遮蔽物體。 |
| 自我遮蔽 | 選擇哪些網格應該影響目前網格的環境遮蔽。 |
| 衰減 | 改變遮蔽因遮蔽距離而衰減的方式。 |
| 地平面 | 啟用此功能以建立一個作為遮蔽器的地面平面。 |
| 地面平面偏移 | 改變接地平面的位置。 |

## 曲率貼圖設定

| 背景設定 | 功能 |
| --- | --- |
| 方法 | 選擇如何產生曲率地圖。 |
| 次級射線 | 調整產生曲率貼圖所需的次級光線數量。 更多的次級射線可以產生更好的結果，但代價是處理時間會增加。 |
| 取樣半徑 | 調整烘焙師搜尋的距離，以計算當前點的曲率。 |
| 相對於邊界盒 | 當勾選時，所有距離都是根據網格邊界框的大小計算。 |
| 自交 | 選擇在決定曲率時會考慮哪些物體。 |
| 自動色調貼圖（每個 UV 圖塊） | 勾選此選項即可自動根據每個 UV 圖塊調整色調貼圖曲率貼圖。 |
| 音色映射最小值 | 如果自動 tonemapping 被關閉，請調整 tonemapping 的最小值。 |
| 音色映射 Max | 如果自動音色映射被關閉，請調整音調映射的最大值。 |

## 位置圖設定

| 背景設定 | 功能 |
| --- | --- |
| 模式 | 選擇是否產生全軸位置圖，或僅計算所選軸的位置。 |
| 軸心國 | 若選擇單軸模式，使用此設定來選擇要計算的軸。 |
| 正規化類型 | 改變位置值的正規化方式，可以用包圍盒、包圍球體，或是關閉正規化。 |
| 正規化尺度 | 改變位置空間的最大界限。 |

| 背景設定 | 功能 |

| 最大防護距離 | 超出此距離且未觸及高多邊形網格的光線被視為未被遮蔽，不會影響厚度貼圖。 |
| 相對於包圍盒 | 勾選此框後，其他與距離相關的設定會根據專案網格的邊界框來設定。 距離 1 等於包圍盒的大小。 |
| 擴散角 | 調整產生光線的角度範圍。 較高的展出角度使表面更容易被非垂直於表面的幾何形狀遮蔽。 |
| 分布 | 選擇光線的分布方式。 |
| 自我遮蔽 | 選擇哪些網格應該影響目前網格的厚度。 |
| 正規化 | 改變厚度值的正規化方式。 |

## 高度圖設定

| 背景設定 | 功能 |
| --- | --- |
| 正規化 | 改變高度值的標準化方式。 |
| 縮放除子 | 如果標準化設定為手動，使用這個滑桿調整縮放除數並調整高度貼圖的標準化。 |
