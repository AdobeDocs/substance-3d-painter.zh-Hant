# 匯出視窗

![](../../assets/export-textures-window.png){width="500px"}

開啟 <b>匯出視窗 </b>，使用檔案 <b>> 匯出貼圖 </b>或鍵盤快捷鍵 <b>Ctrl + Shift + E</b>。

<b>匯出視窗</b>分為三個分頁：

* [匯出設定](export-settings.md)
* [輸出範本](output-templates.md)
* [出口列表](list-of-exports.md)

視窗底部有幾個按鈕：

* <b>全部重設</b> （僅限設定 <b>分頁</b>）：重設專案的匯出設定。
* <b>取消</b>：關閉視窗但不儲存任何變更。
* <b>儲存設定</b>：將目前的匯出設定存入專案中。
* <b>匯出</b>：從目前匯出設定開始匯出，並自動切換到 <b>匯出</b> 清單區塊以追蹤匯出進度。
