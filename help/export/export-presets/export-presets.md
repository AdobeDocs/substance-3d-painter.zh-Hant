# 輸出範本

![](../../assets/preset-list.png)

Substance 3D Painter 有兩種輸出範本，可用來控制匯出流程的行為。

* [預設輸出範本](default-presets.md)設計用於特定 3D 應用程式或工作流程，並可在匯出視窗</b>的<b>輸出範本標籤中</b>取得<b>。你可以複製並修改預設範本，或從零開始建立自己的範本。
* [預定義的輸出範本](../../export/export-presets/predefined-presets/predefined-presets.md) 無法被修改。 預設範本會出現在匯出視窗設定標籤<b></b>的輸出範本下拉選單</b><b>頂端<b>。</b>
