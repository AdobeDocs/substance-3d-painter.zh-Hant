# 預設輸出範本

以下是預設提供的額外輸出範本清單。預設輸出範本可在匯出視窗</b>的<b>輸出範本標籤</b>中複製與修改<b>。

>[!NOTE]
>
> 其他未列入的軟體也可能支援（例如  **Octane**）。 更多資訊 [請參閱生態系統與外](https://experienceleague.adobe.com/zh-hant/docs/substance-3d/ecosystem/home)掛程式。

| *預設* | *描述* |
| --- | --- |
| <b> 亞馬遜木材場 </b> | 請標明並包裝材質，供進口並用於亞馬遜木材場。 |
| <b> Arnold（AiStandard） </b> | Arnold（AiStandard 著色器）的預設。 |
| <b> Arnold UDIM 遺產（AiStandard）</b> | Arnold UDIM Legacy（AiStandard）預設。 |
| <b>Blender（原則BSDF）</b> | 為 Blender（Principled BSDF）預設。 |
| <b> 新冠 </b> | 預設為 Corona 渲染器。 |
| <b> CryEngine 3 </b> | 命名並包材質，匯入並用於 Cry Engine 3。 |
| <b> Dota 2 </b> | 為遊戲 Dota 2 預設（可搭配相關模板使用）。 |
| <b> 關鍵射擊 </b> | 預設為 Keyshot 渲染器。 |
| <b>關鍵攝影 9+</b> | 從 9 版開始，為 Keyshot 渲染器預設。 |
| <b> 鏡頭工作室 </b> | 為 Lens Studio 預設（用來為 Snapchat 製作素材）。 |
| <b>Maxwell（金屬粗糙）</b> | 使用 Metallic Roughness 工作流程為 Maxwell 渲染器預設。 |
| <b>Maxwell（鏡面光澤）</b> | 使用 Specular Glossiness 工作流程為 Maxwell 渲染器預設。 |
| <b> 網格地圖 </b> | 把貼圖集烘焙的網格貼圖槽逐個匯出（匯出解析度與貼圖集相同）。 |
| <b>非PBR鏡面光澤</b> | 為非 PBR 鏡面光澤工作流程命名並匯出材質。 |
| <b> PBR 金屬粗糙度</b> | 在一般金屬/粗糙度 PBR 工作流程中，命名並匯出材質。 |
| <b> PBR 金屬粗糙度（摺疊或 PSD 群組） </b> | 類似 PBR MetalRough，但會建立一個額外的資料夾。 此預設主要適用於 PSD 檔案格式。 |
| <b> PBR 鏡面光澤</b> | 命名並匯出一般 Specular/Glossiness PBR 工作流程所需的材質。 （材質是從 BaseColor/Metallic 工作流程轉換而來。） |
| <b> PBR 鏡面光澤（由金屬粗糙度轉換而來）</b> | 將基色、金屬色和粗糙度通道轉換成相容於 Specular/Glissiness 工作流程。 |
| <b> 紅移 </b> | Redshift 渲染器的預設。 |
| <b>Renderman（pxrDisney）</b> | 為 Renderman 預設，使用 Metallic 和 Rougness 貼圖。 |
| <b>Renderman（pxrSurface）</b> | 為 Renderman 預設，使用漫反射與鏡面貼圖。 |
| <b>Roblox（MaterialVariant）</b> | 預設為使用 Albedo，沒有 alpha 支援的 Roblox。 |
| <b>Roblox（SurfaceAppearance）</b> | 用 Colormap 搭配 alpha 通道為 Roblox 預設。 |
| <b> 陰影3D </b> | 預設為 Shade 3D。 |
| <b>Spark AR 工作室</b> | Spark AR Studio 預設。 |
| <b>Unity HD 渲染管線（金屬標準）</b> | 為 Unity 的 HD 渲染管線預設，使用金屬色和光澤貼圖。 |
| <b>Unity HD 渲染管線（Specular）</b> | 為 Unity 的 HD 渲染管線預設，並新增了鏡面貼圖。 |
| <b>Unity 通用渲染管線（金屬標準）</b> | 為 Unity 的 Universal 渲染管線預設，使用金屬色與平滑度貼圖。 |
| <b>Unity 通用渲染管線（Specular）</b> | 為 Unity 的 Universal 渲染管線預設，包含鏡面貼圖和平滑貼圖。 |
| <b> Unreal 引擎（已打包） </b> | 在 Unreal Engine 中使用的名稱和包貼圖，並以最低記憶體佔用量。 |
| <b>Unreal Engine SSS（已打包）</b> | 在 Unreal 引擎中，使用最低記憶體佔用的材質名稱與包材質，並以次表面散射取代不透明度貼圖。 |
| <b> Vray Next（金屬粗糙）</b> | 使用 PBR 工作流程預設為 Vray 渲染器。 |
| <b>Vray Next（鏡面光澤）</b> | 使用非 PBR 工作流程的 Vray 渲染器預設。 |
| <b> Vray UDIM 傳承（金屬粗糙）</b> | Vray 渲染器預設（UDIM 命名規則）。 |
