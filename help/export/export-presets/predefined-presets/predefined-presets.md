# 預定義輸出範本

預設輸出範本無法編輯，它們是由 Substance 3D Painter 本身產生的。 預設輸出範本會出現在匯出視窗設定標籤<b></b>的輸出範本下拉選單</b><b>頂端<b>。</b>

以下是可用的不可編輯預設列表：

* 2D 視角
* 文件通道 + 普通 + AO（無 Alpha）
* 文件通道 + Normal + AO（含 Alpha）
* Sketchfab
* Substance 3D Stager
* [USDz（Apple AR）](usd-pbr-metal-roughness-preset.md)
* glTF PBR 金屬粗糙度
* glTF PBR 金屬粗糙度 + 位移紋理（實驗性）
