# 膠片顆粒

![](../../assets/v12_post_grain.jpg)

在影像中加入膠片顆粒雜訊圖案，模擬類比攝影底片的有機質感。

| <b>參數</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | 控制木紋的可見度與強度。 較高的數值會產生更明顯、更明顯的雜訊。 |
| <b>半徑</b> | 設定單一顆粒的像素大小。 數值越小，紋理越細緻、細膩;數值越大，紋理越粗糙且更明顯。 |
| <b>類型</b> | 可選擇單色或彩色噪音。 |

>[!NOTE]
>
> 每次視窗刷新時，這個效果產生的雜訊都會被重新產生。 這就是為什麼當產生陰影或旋轉攝影機時，噪音會更新。
