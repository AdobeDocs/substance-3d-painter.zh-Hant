# 鏡頭畸變

![](../../assets/lens-distortion-2.jpg)![](../../assets/lens-distortion-3.png)

鏡頭畸變是一種光學現象，會導致影像向周邊膨脹或收縮。 這種膨脹稱為桶狀變形，收縮則稱為針墊變形。\
相機鏡頭越好，這些現象發生就越少。 此效果可用來模擬不完美的鏡頭，從而呈現更逼真的影像。

| *背景設定* | *描述* |
| --- | --- |
| **動力** | 控制從螢幕邊緣施加變形的速度。 |
| **視野角** | 控制鏡頭變形的程度（模擬視野）。 |
| **邊緣圓度** | 控制邊緣或視窗的圓形。 |
| **邊緣光滑度** | 控制視窗黑色邊緣的硬度與平滑度。 |
