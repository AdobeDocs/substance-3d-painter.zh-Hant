# 磨利

![](../../assets/v12_post_sharpen.jpg)

強化影像的邊緣與細節，以提升感知銳利度。

| <b>參數</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | 控制銳化效果的強度。 較高的數值會讓邊緣對比度更明顯。 |
| <b>直徑</b> | 設定銳化效果的像素大小。 較小的數值能銳化細節;較大的數值則影響較寬的邊緣，並能創造更明顯的效果。 |
