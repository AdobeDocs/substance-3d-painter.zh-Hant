# 光暈

![](../../assets/v12_post_bloom.jpg)

在場景中明亮區域周圍產生柔和的光暈。 模擬光線在明亮光環中散射的現象。

| <b>參數</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | 控制光暈效應的強度。 較高的光輝會在明亮區域周圍產生更明顯的光澤。 |
| <b>門檻</b> | 設定觸發光暈所需的最低亮度。 只有比這個值更亮的像素才會發光。 閾值為 1.0 表示只有比螢幕白色更亮的像素會泛光。 |
| <b>衰減</b> | 決定了花朵從明亮區域擴散的距離。 較低的數值會產生更緊湊的光暈，而較高的數值則將效果擴散到更大範圍。 |
