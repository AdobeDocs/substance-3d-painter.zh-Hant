# 後製

![](../../assets/v12_banner_post_effects2.jpg)

後期特效是可用於Substance 3D Painter視口渲染影像的濾鏡，以模擬常見的攝影機效果。

後期效果可透過 [顯示設定](../../interface/display-settings/display-settings.md) 視窗在任何專案中啟用。

>[!NOTE]
>
> 這些後期效果不會套用到 2D 視圖，以方便使用。 只有 3D 視角顯示影像結果和特效。

以下頁面說明目前支援的各種後製處理效果：

* [景深](depth-of-field.md)
* [光暈](bloom.md)
* [刺眼](glare.md)
* [鏡頭光暈](lens-flare.md)
* [側向像差](lateral-aberration.md)
* [小插曲](vignette.md)
* [磨利](sharpen.md)
* [膠片顆粒](film-grain.md)
* [色調對應](tone-mapping.md)
* [色彩校正](color-correction.md)

查找材質表也可用來微調最終影像結果。 欲了解更多資訊，請參閱[色彩設定](color-profile.md)檔文件。
