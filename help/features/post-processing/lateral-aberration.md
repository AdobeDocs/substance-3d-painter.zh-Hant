# 側向像差

![](../../assets/v12_post_aberration.jpg)

透過將色彩通道從影像中心向外移動，模擬色差，重現真實相機鏡頭邊緣可見的色差。

| <b>參數</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | 控制色彩邊緣效果的強度。 較高的數值會產生更明顯的通道間距。 |
| <b>半徑</b> | 控制未受影響中心區域的大小。 較小的數值會將像差效應推向更接近中心，影響更多影像區域。 |
| <b>柔和度</b> | 控制校正中心與像差邊緣之間過渡的平滑度。 |
| <b>比率</b> | 設定受影響區域的長寬比。 值為1時會形成圓形;值大於1時會產生較寬的橢圓形圖案。 |
| <b>中鋒X</b> | 像差輻射來源光學中心的水平位置。 |
| <b>中心 Y</b> | 光學中心的垂直位置，該中心是像差輻射來源。 |
| <b>消色差像差</b> | 將像差顏色從標準彩虹調切換成綠色/紫色調。 |
