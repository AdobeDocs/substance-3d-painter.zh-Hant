# 插件

Substance 3D Painter 有專用的腳本 API，允許建立自訂外掛以增加自訂功能與行為。\
這些外掛以 Javascript 撰寫，並可與 QML 語言結合，在應用程式內建立自訂介面。 想了解更多 API 內容，請參考腳本文件（可從應用程式的說明選單取得）。

## 預設插件

Substance 3D Painter 有兩個預設插件，展示不同的功能。

* [自動存檔](autosave.md)
* [資源更新器](resources-updater.md)
