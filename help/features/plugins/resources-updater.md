# 資源更新器

![](../../assets/resources-updater-window.png)

**Resources Updater** 外掛允許瀏覽目前已開啟專案中的資源。\
每個資源都可以被架子上其他資源取代。 紅色顯示的資源表示「過時」，表示書架上有不同版本的同一資源，且（很可能）較近期。
