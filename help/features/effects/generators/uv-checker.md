# 紫外線檢查器

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>在：</strong> UV、邊框、隨機</td>
    <td style="border: 0;" valign="top"><strong>說明</strong><br>UV 檢查器產生器會套用格狀的檢查器圖案，讓你能輕鬆發現像是拉伸、比例不均或變形等 UV 問題。 <br><br>UV Checker 產生器通常直接用於填充層，以觀察 UV 變形。</td>

## 參數

<table>
  <tr>
    <th>參數名稱</th>
    <th>說明</th>
  </tr>
  <tr>
    <td><strong>種子</strong></td>
    <td>設定用來產生泥土材質的種子值。 <br><ul><li>點擊隨機可以切換到另一個隨機種子。</li><li>點擊鉛筆查看目前的種子值，若需要則輸入特定值。</li></ul></td>
  </tr>
  <tr>
    <td><strong>棋盤格色彩模式</strong></td>
    <td>選擇顏色分配方式：<br><ul><li><strong>統一</strong>：在整個材質集上套用相同的顏色。</li><li><strong>隨機</strong>：為每個紫外線島嶼套用隨機顏色。</li></ul></td>
  </tr>
  <tr>
    <td><strong>棋盤格色彩</strong></td>
    <td>設定棋盤格圖案的顏色。</td>
  </tr>
  <tr>
    <td><strong>棋盤格子圖塊</strong></td>
    <td>調整棋盤格圖案的大小。</td>
  </tr>
  <tr>
    <td><strong>棋盤格不透明度</strong></td>
    <td>調整格網的透明度。 在 0 透明度下，只有棋盤紋理可見，沒有格子。</td>
  </tr>
  <tr>
    <td><strong>UV 邊框色彩</strong></td>
    <td>設定 UV 邊界的顏色。</td>
  </tr>
  <tr>
    <td><strong>UV 邊界寬度</strong></td>
    <td>調整 UV 邊界的寬度。</td>
  </tr>
</table>
