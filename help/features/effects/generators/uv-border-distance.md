## 參數

| 參數名稱 | 說明 |
| --- | --- |
| **倒轉** | 將發電機輸出反轉。 |
| **平衡** | 調整效果的平衡，將中點像亮度控制一樣往黑或白移動。 |
| **對比** | 調整效果的對比度/衰減。 |
| **平滑度** | 調整效果的圓滑度。 當使用低 **平滑度** 值時，這點最為明顯。 |
| **距離** | 調整效果從 UV 邊界延伸的距離。 |
