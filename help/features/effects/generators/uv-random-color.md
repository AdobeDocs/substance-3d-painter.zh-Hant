# 紫外線隨機色彩

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_random_color.png" alt=""/><br><strong>在：</strong> 實用性、面具</td>
    <td style="border: 0;" valign="top"><strong>說明</strong><br>UV 隨機色彩產生器會為每個 UV 島嶼分配純色且獨特的顏色。 這通常作為複雜網格的診斷工具非常有用。<br><br>UV隨機色彩可以用來建立遮罩（黑白輸出），或直接作為填充層，根據UV島為網格施加顏色變化，例如隨機化木地板的每塊木板。</td>
  </tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| **自訂漸層** | 使用漸層圖來定義色彩範圍。 |

## 參數

<table>
  <tr>
    <th>參數名稱</th>
    <th>說明</th>
  </tr>
  <tr>
    <td><strong>種子</strong></td>
    <td>設定用來產生泥土材質的種子值。 <br><ul><li>點擊隨機可以切換到另一個隨機種子。</li><li>點擊鉛筆查看目前的種子值，若需要則輸入特定值。</li></ul></td>
  </tr>
  <tr>
    <td><strong>色彩來源模式</strong></td>
    <td>決定所使用的色彩來源模式。 <br><ul><li><strong>隨機</strong>：在隨機模式下，顏色會隨機定義並分配。</li><li><strong>自訂漸層</strong>：在自訂漸層模式中，你有額外輸入可以新增自訂漸層地圖，從中選取顏色。</li></ul></td>
  </tr>
</table>
