# 世界空間法線

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_world_space_normals.png" alt=""/><br><strong>在：</strong> 遮罩、產生器、灰階、混合</td>
    <td style="border: 0;" valign="top"><strong>描述</strong><br>：世界空間法線產生器會使用烘焙的世界空間法線貼圖，根據每個表面在3D空間中面向的方向來為模型上色或套用效果。 例如，從上到下。<br><br>世界空間法線產生器輸出單色（黑白）材質。 因此，它很適合生成遮罩，根據臉部方向施加各種效果，如泥土、灰塵、雪或鏽蝕。<br><br>需要烘焙的位置和世界空間法線貼圖作為影像輸入。 <a href="../../../baking/baking.md">在這裡了解更多烘焙知識</a>。</td>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| **材質** 色彩 | 使用自訂材質或錨點。 |
| **世界空間法線色彩** | 使用烘焙的世界空間法線貼圖。 |
| **位置漸層** 顏色 | 使用烘焙的位置貼圖。 |

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| **全球反轉** | 所有效果合併後，將最終結果反轉。 |
| **全球模糊** | 在所有效果合併後，均勻軟化最終遮罩。 |
| **全球平衡** | 在所有效果合成後，將最終遮罩的平衡調整為黑或白，就像調整亮度一樣。 |
| **全局對比** | 在所有效果合併後調整最終遮罩的對比度。 |
| **使用材質** | 切換自訂材質貼圖的使用開關。 |

### 世界太空常態

| 參數名稱 | 說明 |
| --- | --- |
| **倒轉** | 只反轉世界空間法線。 |
| **模糊** | 平滑世界空間法線。 |
| **平衡** | 只調整世界空間法線的平衡，將中點像亮度控制一樣往黑或白移動。 |
| **對比** | 只調整世界空間法線的對比度/衰減。 |
| **亮度** | 只調整世界空間法線的亮度。 |
| **從右到左** | 調整效果在網格上的應用方式，從左到右。 |
| **從上到下** | 調整效果從上到下在網格上的套用方式。 |
| **從前到後** | 調整效果從前到後在網格上的套用方式。 |

#### 世界空間法線/從右到左

| 參數名稱 | 說明 |
| --- | --- |
| **倒轉** | 將從右到左的漸變方向反轉。 |
| **混合模式** | 選擇 [目前圖層要使用的混合模式](../../../interface/layer-stack/blending-modes.md) 。 |

#### 世界空間標準/從上到下

| 參數名稱 | 說明 |
| --- | --- |
| **倒轉** | 將從上到下的漸層方向反轉。 |
| **混合模式** | 選擇 [目前圖層要使用的混合模式](../../../interface/layer-stack/blending-modes.md) 。 |

#### 世界空間標準/從前到尾

| 參數名稱 | 說明 |
| --- | --- |
| **倒轉** | 將前後漸變方向反轉。 |
| **混合模式** | 選擇 [目前圖層要使用的混合模式](../../../interface/layer-stack/blending-modes.md) 。 |
