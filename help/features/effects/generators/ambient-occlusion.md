## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| 材質色彩 | 使用自訂材質或錨點。 |
| 微型標準色彩 | 使用自訂的法線貼圖或錨點。 |
| 微高色彩 | 使用自訂材質或錨點。 |
| 環境遮蔽灰階 | 使用烘焙好的環境遮蔽地圖。 |
| 世界空間法線色彩 | 使用烘焙的世界空間法線貼圖。 |
| 位置漸層顏色 | 使用烘焙的位置貼圖。 |

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| **全球反轉** | 所有效果合併後，將最終結果反轉。 |
| **全球模糊** | 在所有效果合併後，均勻地將最終遮罩平滑。 |
| **全球平衡** | 在所有效果合成後，將最終遮罩的平衡調整為黑或白，就像調整亮度一樣。 |
| **全局對比** | 在所有效果合併後調整最終遮罩的對比度。 |
| **使用材質** | 切換自訂材質貼圖的使用開關。 |
| **使用微觀細節** | 開啟或關閉自訂微觀細節的使用。 |

### 環境遮擋

| 參數名稱 | 說明 |
| --- | --- |
| **倒轉** | 只反轉環境光遮蔽和微觀細節。 |
| **模糊** | 畫面平滑，只有環境光遮蔽和微觀細節。 |
| **平衡** | 調整環境光遮蔽和微觀細節的平衡，將中間點像亮度控制一樣往黑或白移動。 |
| **對比** | 只調整環境光遮蔽和微觀細節的對比度/衰減。 |

### 微觀細節

| 參數名稱 | 說明 |
| --- | --- |
| **微高** | 切換自訂微高度地圖的使用。 |
| **微型正常** | 切換自訂微法線貼圖的使用。 |
| **AO半徑** | 微細調整環境遮蔽的半徑（範圍）。 |
| **AO 深度** | 在微觀細節中調整環境遮蔽的深度（強度）。 |
