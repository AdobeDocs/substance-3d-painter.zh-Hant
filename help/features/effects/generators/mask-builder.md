# 面具製作者

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_mask_builder_dark.png" alt=""/><strong>收錄於：</strong> mask、generator</td>
    <td style="border: 0;" valign="top"><strong>說明</strong><br>面具編輯器產生器是面具編輯器產生器的舊版。 它是一款多功能的遮罩產生器，讓你能將 Grunge、AO、Curvature、漸層、世界空間法線、刮痕、散布和微細節整合在一個遮罩中。<br><br>Mask Builder 產生器非常靈活，但由於其複雜性，對效能的影響比大多數產生器更大。<br><br>Mask Builder 產生器輸出單色（黑白）材質。 因此，它對於根據各種烘焙的地圖產生遮罩非常有用。 <br><br>需要烘焙位置、曲率、環境遮蔽及世界空間法線貼圖作為影像輸入。 <a href="../../../baking/baking.md">在這裡了解更多烘焙知識</a>。</td>
  </tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| **世界空間法線** 顏色 | 使用烘焙的世界空間法線貼圖。 |
| **自訂 grunge 1** 灰階 | 使用自訂材質或錨點。 |
| **自訂垃圾搖滾2** 灰階 | 使用自訂材質或錨點。 |
| **散射輸入** 灰階 | 使用自訂材質或錨點。 |
| **位置** 顏色 | 使用烘焙的位置貼圖。 |
| **曲率** 灰階 | 使用烘焙好的曲率地圖。 |
| **環境遮蔽** 灰階 | 使用烘焙好的環境遮蔽地圖。 |
| **微型標準** 色彩 | 使用自訂的法線貼圖或錨點。 |
| **微高** 色彩 | 使用自訂材質或錨點。 |

### 頹漬風

| 參數名稱 | 說明 |
| --- | --- |
| **規模** | 調整垃圾紋理的大小。 |
| **使用自訂垃圾搖滾** | 開啟或關閉自訂 Grunge 地圖的使用。 這只是 Custom Grunge 1 的能見度問題。 要控制自訂垃圾搖滾2的可見度，請調整次要自訂垃圾搖滾滑桿。 |
| **次要訂製垃圾搖滾** | 調整 Custom Grunge 2 材質的可見度。 |
| **倒轉** | 顛倒垃圾搖滾地圖。 |

### 環境遮擋

| 參數名稱 | 說明 |
| --- | --- |
| **分布範圍** | 調整 AO 遮罩的範圍。 |
| **對比** | 調整 AO 遮罩的對比度/衰減。 |
| **噪音** | 在 AO 結果中加入雜訊，有效地降低遮罩的亮度。 |
| **倒轉** | 把 AO 遮罩反轉。 |

### 曲率

| 參數名稱 | 說明 |
| --- | --- |
| **凸範圍** | 調整遮罩標示所需的最小凸角。 |
| **凸對比** | 調整凸面遮罩的對比度。 |
| **凸反轉** | 將凸面罩反轉。 |
| **凹形範圍** | 調整遮罩標示的最小凹角。 |
| **凹形對比** | 調整凹面遮罩的對比度。 |
| **凹面倒轉** | 把凹面罩倒轉。 |
| **平滑度** | 調整曲面遮罩中明暗區域的混合。 |
| **等級提升** | 利用這個來擴展遮罩區域的範圍。 這就像凸範圍&#x200B;**和**&#x200B;凹範圍&#x200B;**參數的乘數**。 |
| **噪音** | 在曲率結果中加入雜訊，有效地降低遮罩的亮度。 |

### 梯度

梯度位置是基於位置貼圖，該貼圖可以用全場景或材質標準化尺度烘焙。 如果你的材質只出現在場景的一小區域，但位置圖是用 Full Scene Normalization 尺度烘焙的，調整漸層範圍以達到理想效果可能會很困難。

| 參數名稱 | 說明 |
| --- | --- |
| **分布範圍** | 調整漸層範圍。 |
| **對比** | 調整漸層對比度。 |
| **倒轉** | 反轉梯度。 |

### 世界太空常態

**前**、**後、****左****、右**&#x200B;的數值可能不對應網格的前、後、左、右。預設情況下， **前方** 對應正 X 軸，右方對應正 Z 軸。

| 參數名稱 | 說明 |
| --- | --- |
| **最高強度** | 調整自上而下漸層的範圍（強度）。 |
| **底部強度** | 調整自下而上漸層的範圍（強度）。 |
| **前緣強度** | 調整前後漸變的範圍（強度）。 |
| **背部強度** | 調整後方前方漸變的範圍（強度）。 |
| **右度強度** | 調整右左漸層的範圍（強度）。 |
| **左側強度** | 調整左右漸層的範圍（強度）。 |

### 刮痕

| 參數名稱 | 說明 |
| --- | --- |
| **金額** | 調整刮痕的密度。 |
| **規模** | 調整刮痕的大小。 |

### 散佈圖

| 參數名稱 | 說明 |
| --- | --- |
| **規模** | 調整散射效果的大小。 較大比例會產生更多且較小的郵票，而較低比例則增加單張郵票的尺寸，但可見的郵票數量較少。 |
| **密度** | 調整散落郵票的數量。 |
| **規模** | 調整散落郵票的大小。 |
| **尺寸變化** | 調整散落郵票大小的隨機性。 尺寸變異越大，郵票尺寸會隨機減少，因此增加尺寸變異可能意味著你也需要增加尺寸值以維持相同的平均尺寸。 |
| **不透明度變異** | 調整每個散落郵票不透明度的隨機性。 |
