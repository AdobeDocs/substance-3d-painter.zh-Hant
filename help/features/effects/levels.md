# 關卡

音量是一種用來調整影像色彩範圍的效果。 它能平衡和調色顏色和/或灰階的明暗。 你可以打開效果選單來新增：

![](../../assets/level-menu.png)

主要介面會顯示一個直方圖（介面中央的色彩山），以表示像素在每個色彩強度層級下如何分布。 直方圖顯示陰影（左側）、中間調（中間部分）及高光（右側）的細節。 直方圖也能快速顯示色彩的色調範圍，幫助判斷影像的暗暗或亮度。

![](../../assets/image2015-3-20-11-24-24.png)

為了調整影像的色彩範圍，直方圖的頂部和底部有兩組控制項可用：

* 頂部三個按鈕可控制陰影、中間調與高光，並可用來重新分配色調範圍，以對比整體影像。
* 底部兩個按鈕控制影像的黑白點（通常是 0 和 255）。 例如，這對於反轉影像的顏色非常有用。

>[!NOTE]
>
> 音量效果一次只能套用到一個頻道，依受影響頻道&#x200B;*選項選擇*。如果你想在多個聲道上套用一個音量，就必須建立多個等級效果。

* 右上角的「色彩」下拉選單可以讓你調整整張 RGB 影像的音量，或只調整紅、綠、藍三色通道中的一個。
* 右下角的夾具選項可以讓你夾住 0 到 1 之間的音量（0-255）。 在處理非 HDR 頻道（像 **是 Base Color**）時，這個選項應該一直勾選。
