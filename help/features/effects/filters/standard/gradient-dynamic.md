# 梯度動態

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![漸層動態圖示](./Resources/icon_gradient_dynamic.png "漸層動態")

<b>在：</b> 效果/漸層、灰階、重新映射

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

漸層動態濾波器將影像中的灰階值重新映射為由特定點的顏色所定義的漸層。

它用於貼圖層或遮罩內部（黑白輸出），用以從另一張影像取樣的漸層重新映射灰階值。

</td>
</tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>漸變來源：</b> 色彩 | 使用自訂的色彩貼圖或錨點。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>梯度方向：</b> | 選擇梯度來源是水平取樣還是垂直取樣。 |
| <b>梯度輸入位置：</b> | 調整從梯度輸入取樣的位置。 |
