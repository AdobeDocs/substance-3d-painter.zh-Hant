# 填充區域顏色

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>內容：</b> 效果/填充、形狀、輪廓、RGBA、色彩

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

填充區域顏色濾鏡會將輪廓轉換成填充形狀。 任何有連續邊界的區域都會被填滿。 彩色版本則使用 alpha 來決定區域邊界。

它用於顏料層（色彩通道）中，填補封閉的筆觸。

</td>
</tr>
</table>

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>區域偵測：</b> | 選擇如何標示要填滿的區域。 |
| <b>區域偵測閾值：</b> | 調整區域偵測閾值。 |
| <b>除錯區域偵測：</b> | 透過區域偵測設定切換輪廓的顯示。 這有助於辨識尚未完全封閉的區域。 |
| <b>紫外線邊界行為：</b> | 選擇填滿區域時如何處理 UV 邊框。 |
| <b>紫外線邊界閾值：</b> | 調整忽略原本可能被區域偵測填滿的紫外線區域的閾值。 |
| <b>彩色模式：</b> | 選擇用哪種方法填滿該區域內部。 |
| <b>填充顏色：</b> | 調整填充顏色。 |
| <b>模糊強度：</b> | 調整模糊強度。 |
| <b>模糊樣本：</b> | 調整模糊取樣的數量。 |
| <b>擴散迭代：</b> | 調整要執行的擴散迭代次數。 較高的數值會改善結果，但速度會較慢。 有用的數值在 [8,48] 左右。 |
