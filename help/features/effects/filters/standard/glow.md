## 說明

Glow 濾光片會在輸入可見部分周圍產生外層光暈。

它用於貼圖層或遮罩內部（黑白輸出），以在形狀和材質周圍增加柔和或精確的光暈。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>用於面具：</b> | 切換是否使用光斑。 |
| <b>模式：</b> | 選擇發光模式是使用柔和模式還是精確模式。 |
| <b>寬度：</b> | 調整光暈的寬度。 |
| <b>讓分：</b> | 調整光暈的擴散範圍。 |
| <b>不透明度：</b> | 調整光暈的不透明度。 |
| <b>顏色：</b> | 調整光色。 |
