## 說明

色彩校正濾鏡會針對高光、中間調和陰影做出定音調整。

它用於填充層，以進行細微的對比度、亮度和飽和度調整。

## 參數

### 陰影

| 參數名稱 | 說明 |
| --- | --- |
| **對比：** | 調整陰影的對比度。 |
| **亮度：** | 調整陰影的亮度。 |
| **飽和度：** | 調整陰影的飽和度。 |

### 中間調

| 參數名稱 | 說明 |
| --- | --- |
| **對比：** | 調整中間調的對比度。 |
| **亮度：** | 調整中間調的亮度。 |
| **飽和度：** | 調整中間調的飽和度。 |

### 亮部

| 參數名稱 | 說明 |
| --- | --- |

| **亮度：** | 調整高光的亮度。 |
| **飽和度：** | 調整高光的飽和度。 |
