## 說明

鏡像濾波器是一種對稱濾波器，用來複製輸入的一部分。

它用於貼圖層（顏色）或遮罩上，根據鏡像軸對完整的材質、遮罩、形狀等進行鏡像。

</td>
</tr>
</table>

>[!NOTE]
>
> 鏡像濾鏡是在 UV 空間運作，因此在視窗&#x200B;**中開啟 2D 視圖**&#x200B;可能會很有用。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>顯示除錯：</b> | 切換除錯視圖的顯示。 |
| <b>模式：</b> | 選擇鏡像模式。 |
| <b>軸 X 偏移：</b> | 調整 X 軸偏移。 |
| <b>軸向Y偏移：</b> | 調整Y軸偏移。 |
| <b>反轉軸 X：</b> | 切換 X 軸的反轉。 |
| <b>反轉軸Y：</b> | 在Y軸切換反轉。 |
| <b>角型：</b> | 選擇鏡像角的處理方式。 |
