## 說明

Pixelate 濾波器會將輸入轉換成大方塊，模擬像素化的外觀。

它用於貼圖層（顏色）或遮罩上，對完整的材質、雜訊、遮罩、形狀等進行像素化。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>像素數量：</b> | 調整像素數量，這會帶來改變像素大小的副作用。 像素越多，像素越小。 |
| <b>申請 Alpha：</b> | 切換濾波器是否也會修改 Alpha 通道。 |
