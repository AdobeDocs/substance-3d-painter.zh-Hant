## 說明

投影濾鏡會產生投影。

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>角度：</b> | 調整陰影角度。 |
| <b>距離：</b> | 調整陰影距離。 |
| <b>尺寸：</b> | 調整陰影大小。 |
| <b>讓分：</b> | 調整陰影的擴散。 |
| <b>不透明度：</b> | 調整陰影的透明度。 |
| <b>顏色：</b> | 調整陰影顏色。 |
