## 說明

轉換濾波器用於轉換（縮放、旋轉、偏移）圖層。

它用於貼圖層或遮罩內部（黑白輸出），例如轉換圖案、形狀等。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>重複模式：</b> | 選擇重複模式。 |
| <b>翻轉模式：</b> | 選擇翻轉模式。 |
| <b>調整 X：</b> | 調整結果的 X 縮放。 |
| <b>Y的縮放：</b> | 調整結果的 Y 縮放。 |
| <b>偏移X：</b> | 調整結果的 X 偏移量。 |
| <b>偏移 Y：</b> | 調整結果的Y軸偏移量。 |
| <b>磁磚安全旋轉：</b> | 切換對方塊安全的旋轉。 |
| <b>輪替：</b> | 調整旋轉。 |
| <b>縮放：</b> | 調整整體的縮放。 |
| <b>偏移：</b> | 調整整體偏移量。 |
