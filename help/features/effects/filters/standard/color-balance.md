## 說明

色彩平衡濾鏡會對高光、中間調和陰影做出細微調整。

它用於填充層，進行細微的色彩調整。

## 參數

### 亮部

| 參數名稱 | 說明 |
| --- | --- |
| **青 &lt;-> 紅色：**&lt;/-> | 把顏色往青色或紅色方向移動。 |
| **洋紅色 &lt;-> ：**&lt;/-> | 將顏色轉向洋紅色或綠色。 |
| **黃 &lt;-> 藍：**&lt;/-> | 將顏色轉向黃色或藍色。 |
