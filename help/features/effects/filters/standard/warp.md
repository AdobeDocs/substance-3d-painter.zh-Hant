## 說明

曲速濾波器用於各種變形效果。 扭曲過濾器提供一般扭曲、特定方向扭曲的方向扭曲，以及多方向扭曲以增加變化。

扭曲用於貼圖層或遮罩內部（黑白輸出）來變形材質、形狀、遮罩、輪廓等。

</td>
</tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>自訂噪音</b> | 使用自訂材質作為噪音輸入映射。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>種子：</b> | 隨機分配一個數值，創造出不同的變化，且不改變整體設定。 |
| <b>傳送模式：</b> | 選擇曲速模式。 |
| <b>強度：</b> | 調整曲速強度。 |
| <b>強度分頻器：</b> | 選擇曲速強度的分配方式。 |
| <b>角度：</b> | 調整經線角度。 |
| <b>混合模式：</b> | 選擇扭曲所使用的混合模式。 |
| <b>操作說明：</b> | 選擇曲速方向的數量。 |

### 來源參數

<table>
<tr>
<td><b>來源模式：</b></td>
<td>決定來源模式。<br><br> - 預設噪音：使用預設噪音來產生扭曲效果。<br> - 先前輸入：使用先前輸入來產生扭曲效果。 當填充層套用特定的噪音模式時，使用「先前輸入」模式的扭曲效果會使效果與填充層相同的噪音模式。<br> - 自訂噪音：使用自訂噪音輸入來產生扭曲效果。</td>
</tr>
<tr>
<td><b>來源模糊：</b></td>
<td>會模糊來源雜訊。</td>
</tr>

<td>調整來源雜訊的平衡，將中點向黑或白移動，就像亮度控制一樣。</td>
</tr>
