# 直方圖掃描

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![直方圖掃描圖示](./Resources/icon_histogram_scan.png "直方圖掃描")

<b>收錄於：</b> 特效/灰階

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

直方圖掃描濾波器會重新映射輸入灰階影像的對比度與亮度。

它可以直接用於補色層，或是用於遮罩（黑白輸出）上來調整對比度和亮度。

</td>
</tr>
</table>

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>職位：</b> | 調整直方圖的位置。 |
| <b>對比：</b> | 調整結果的對比度/衰減。 |
| <b>倒立姿勢：</b> | 切換位置的反轉。 在非常高或非常低的位置值時，這實際上會反轉輸出。 |
