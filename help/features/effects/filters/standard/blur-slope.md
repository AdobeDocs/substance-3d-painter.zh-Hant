## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| **自訂雜訊：** 灰階 | 使用自訂材質或錨點作為自訂噪音。 |

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| **種子：** | 隨機分配一個數值，創造出不同的變化，且不改變整體設定。 |
| **強度：** | 調整模糊強度。 |
| **強度分頻器：** | 選擇模糊強度的分配方式。 |
| **混合模式：** | 選擇斜坡模糊所使用的混合模式。 |
| **品質：** | 調整效果的品質。 |

### 來源參數

| 參數名稱 | 說明 |
| --- | --- |
| **資料來源類型：** | 選擇音源是使用預設噪音、先前輸入還是自訂噪音。 |
| **模糊：** | 調整來源雜訊或輸入的模糊強度。 |
| **職位：** | 調整來源噪音或輸入的中點，類似亮度控制。 |
| **對比：** | 調整來源雜訊或輸入的對比度。 |
| **資料來源：Tilling：** | 調整來源雜訊或輸入的平鋪。 |
