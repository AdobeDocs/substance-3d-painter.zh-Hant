# 模糊斜坡

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![模糊斜坡圖示](./Resources/icon_blur_slope.png "模糊斜坡")

<b>收錄於：</b> 特效/模糊、灰階

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

斜率模糊濾鏡會產生模糊或漸變的效果，尤其在色彩間高對比邊緣時特別明顯。

它可以直接用於材質圖層，使整個材質或特定材質模糊，或用於遮罩上模糊遮罩。 它可能造成邊緣剝落或風化、泥土滲漏或鏽蝕等現象。

</td>
</tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>自訂雜訊：</b> 灰階 | 使用自訂材質或錨點作為自訂噪音。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>種子：</b> | 隨機分配一個數值，創造出不同的變化，且不改變整體設定。 |
| <b>強度：</b> | 調整模糊強度。 |
| <b>強度分頻器：</b> | 選擇模糊強度的分配方式。 |
| <b>混合模式：</b> | 選擇斜坡模糊所使用的混合模式。 |
| <b>品質：</b> | 調整效果的品質。 |
