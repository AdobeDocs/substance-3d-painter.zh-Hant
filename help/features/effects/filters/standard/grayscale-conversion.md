# 灰階轉換

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![灰階轉換圖示](./Resources/icon_grayscale_conversion.png "灰階轉換")

<b>在：</b> 效果/色彩、去飽和、最小、最大

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

灰階轉換濾波器透過權重每個色道的亮度，將通道/彩色影像轉換為灰階。 你有很多選項可以調整轉換。

它用於貼圖層或遮罩圖層，將通道轉換成灰階，或將彩色影像轉為灰階並用作遮罩。

</td>
</tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>自訂輸入：</b> 顏色 | 使用自訂材質或錨點。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>頻道輸入：</b> | 選擇用於轉換的頻道輸入。 |
| <b>反轉：</b> | 切換結果的反轉。 |
| <b>平衡：</b> | 調整黑白效果的平衡，類似亮度調整。 |
| <b>對比：</b> | 調整結果的對比度/衰減。 |
| <b>模式：</b> | 選擇灰階轉換模式。 |
| <b>紅色：</b> | 調整紅色通道的權重。 此權重用於計算灰階結果。 |
| <b>綠色：</b> | 調整綠通道的權重。 此權重用於計算灰階結果。 |
| <b>藍色：</b> | 調整藍色通道的權重。 此權重用於計算灰階結果。 |
| <b>Alpha：</b> | 調整 Alpha 通道的權重。 此權重用於計算灰階結果。 |
