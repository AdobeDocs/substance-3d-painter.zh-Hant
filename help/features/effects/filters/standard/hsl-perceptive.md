## 說明

HSL Perceptive 濾鏡可調整色調、飽和度與明暗度。

它用於材質層（顏色）上，以調整色調、飽和度和明暗度。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>模式：</b> | 選擇HSL調整模式。 **感知型** 會根據我們對顏色的感知來調整數值，而 **一般型** 則是根據電腦內部的顏色表現來調整。 |
| <b>Hue：</b> | 調整色調。 |
| <b>飽和度：</b> | 調整飽和度。 |
| <b>輕盈：</b> | 調整明暗。 |
