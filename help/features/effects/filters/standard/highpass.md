## 說明

高通濾波器會產生高通效果，類似同名的 Photoshop 動作。 它對於去除影像中較大的亮度差異非常有用，例如在清理貼圖時。

它用於貼圖層或遮罩層，以消除較大的亮度差異。

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>色彩空間：</b> | 選擇濾鏡使用的色彩空間。 |
| <b>半徑：</b> | 調整高通半徑。 |
| <b>申請 Alpha：</b> | 切換濾波器是否會影響 Alpha 通道。 |
