# 梯度

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![漸層圖示](./Resources/icon_gradient.png "漸變")

<b>收錄於：</b> 特效/灰階

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

漸層濾波器會用自訂漸層重新映射影像中的灰階值。

它可用來調整灰階影像的數值，或透過將輸入映射到自訂漸層來著色。

</td>
</tr>
</table>

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>顯示漸層（除錯）：</b> | 切換漸變除錯視圖的顯示。 |
| <b>顏色數量：</b> | 調整漸層中使用的顏色數量。 |
| <b>線性調色：</b> | 切換線性色彩混合。 |
| <b>顏色1：</b> | 選擇第一個顏色。 |
| <b>顏色1位置：</b> | 調整第一個顏色的位置。 |
| <b>顏色2：</b> | 選擇第二種顏色。 |
| <b>顏色2 位置：</b> | 調整第二個顏色的位置。 |
| <b>顏色N：</b> | 選擇第N種顏色。 |
| <b>顏色 N 位置：</b> | 調整第N個顏色的位置。 |

### 輸入轉換

<table>
<tr>
<td><b>灰階模式：</b></td>
<td>選擇灰階轉換模式。 你可以選擇去飽和度、亮度、平均、最大值和最小值。</td>
</tr>
<tr>
<td><b>模糊強度：</b></td>
<td>調整輸入模糊的程度。</td>
</tr>
<tr>
<td><b>平衡：</b></td>
<td>透過將中點向黑或白移動來調整輸入平衡，類似亮度控制。</td>
</tr>
<tr>
<td><b>對比：</b></td>
<td>調整輸入的對比度。</td>
</tr>
<tr>
<td><b>反轉：</b></td>
<td>切換輸入顏色的反轉。</td>
</tr>
</table>
