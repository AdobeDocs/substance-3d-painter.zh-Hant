## 說明

斜角濾鏡會為灰階形狀和遮罩加上斜邊。

它用於貼圖層或遮罩內（黑白輸出），在形狀邊緣創造斜角浮雕。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>斜面包裹：</b> | 切換繞線讓斜角橫向和垂直排列。 |
| <b>距離：</b> | 調整斜角大小。 |
| <b>角型：</b> | 選擇斜角是圓角還是角角。 |
| <b>平滑化：</b> | 調整斜角所施加的平滑量。 若不進行平滑處理，彎曲斜面可能會因鋸齒而產生明顯的條紋。 |
| <b>模糊模式：</b> | 選擇斜角使用均勻或非均勻模糊。 非均勻模糊會將模糊效果集中在斜角區域，有助於保持細節，但均勻模糊則更為一致。 |
