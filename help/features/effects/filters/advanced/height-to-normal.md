</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

高度至法線濾波器會根據高度通道產生準確的法線資料。

它用於貼圖層，將高度資訊轉換成法線資料。

</td>
</tr>
</table>

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>覆寫現有的正常值：</b> | 切換覆蓋現有的正常資料。 |
| <b>使用世界單位：</b> | 切換使用世界單位來轉換。 |
| <b>正常強度：</b> | 如果 **使用世界單位** 為 **假**，請用此來調整產生的正常值資料強度。 |
| <b>表面積（公分）：</b> | 如果 **「使用世界單位** 」為 **真**，請用此調整所表示表面的寬度或高度，以較大者為準。 |
| <b>高度深度（公分）：</b> | 如果 **「使用世界單位** 」為 **真**，請用它來調整表面的最大高度範圍。 |
