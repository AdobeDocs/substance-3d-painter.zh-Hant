<b>收錄於：</b> 特效/灰階、桑原、各向異性、風格化

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

各向異性桑原濾鏡創造出繪畫風格化效果，同時保留強烈的方向特徵。

它用於貼圖層或遮罩內部（黑白輸出），以創造完整材質、噪音和遮罩的風格化外觀。

</tr>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>半徑地圖：</b> 灰階 | 使用自訂材質或錨點。 |
| <b>自訂輸入：</b> 顏色 | 使用自訂材質或錨點。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>萃取方向：</b> | 選擇濾鏡如何推導模糊方向。 |
| <b>半徑：</b> | 調整模糊半徑。 較高的數值會產生更強烈的模糊效果。 最高數值是32。 |
| <b>順滑度：</b> | 調整沿計算方向混合的顏色比例。 在 0 時，顏色大多會朝那個方向位移，幾乎沒有混合。 |
| <b>銳利度：</b> | 調整模糊區域的對比度，使其看起來更平坦且清晰。 |
| <b>張量平滑度：</b> | 調整從影像計算並儲存在方向圖上的模糊量。 當影像包含大量高頻細節時，較高的數值會產生更平滑的結果。 |
| <b>各向異性：</b> | 調整方向貼圖對模糊影響的強弱。 即使該值為 0，方向圖及其修飾符仍會影響結果，因為該映射用於桑原濾波器核。 |
| <b>各向異性角：</b> | 在轉彎時調整套用到方向圖上的旋轉。 這個旋轉會加到各向異性角度圖輸入的值上。 |
