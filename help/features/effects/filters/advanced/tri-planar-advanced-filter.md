## 說明

三平面進階濾鏡是三平面進階濾鏡的濾鏡版本，具備完整投影的手動控制。 它讓你能控制每個軸的旋轉和偏移值。 與產生器不同，這個濾鏡直接作用於圖層內容，而產生器則需要自訂遮罩輸入來進行混合。

它用於貼圖層或遮罩內部，以增加三平面混合效果。

</td>
</tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>世界空間標準：</b> | 使用烘焙的世界空間法線貼圖。 |
| <b>職位：</b> | 使用烘焙的位置貼圖。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>投影：</b> | 選擇要投影的軸。 |
| <b>混合模式：</b> | 選擇軸投影如何融合在一起。 |
| <b>對比度融合：</b> | 調整投影混合的對比度。 |
| <b>貼圖平鋪：</b> | 調整投影材質的平鋪。 |
| <b>第十輪：</b> | 調整 X 軸投影的旋轉。 |
| <b>偏移X：</b> | 調整 X 軸投影的偏移量。 |
| <b>輪轉Y：</b> | 調整Y軸投影的旋轉。 |
| <b>偏移 Y：</b> | 調整 Y 軸投影的偏移量。 |
| <b>旋轉Z：</b> | 調整Z軸投影的旋轉。 |
| <b>偏移Z：</b> | 調整 Z 軸投影的偏移量。 |

### 軸 X

<table>
<tr>
<td><b>第十輪：</b></td>
<td>調整 X 軸材質投影的旋轉。</td>
</tr>
<tr>
<td><b>偏移 X X：</b></td>
<td>調整 X 軸上的投影偏移。</td>
</tr>
<tr>
<td><b>偏移 X Y：</b></td>
<td>調整 X 軸投影偏移的 Y 軸。</td>
</tr>
</table>

>[!NOTE]
>
> 偏移參數的標題中有兩個軸。 第一個定義投影軸，第二個定義偏移軸。 所以 **偏移 X Y 是** 專門看 X 軸上的投影，並沿著局部投影的 Y 軸偏移該投影。
>
>換個角度想&#x200B;**，偏移X X**&#x200B;在水平&#x200B;**上偏移X投影**，**偏移XY在**&#x200B;垂直&#x200B;**方向偏移X投影**。

### 軸心 Y

<table>
<tr>
<td><b>第十輪：</b></td>
<td>調整 Y 軸材質投影的旋轉。</td>
</tr>
<tr>
<td><b>偏移 Y X：</b></td>
<td>調整 X 軸的 Y 軸投影偏移。</td>
</tr>

<td><b>偏移 Y Y：</b></td>

>[!NOTE]

> 偏移參數的標題中有兩個軸。 第一個定義投影軸，第二個定義偏移軸。 所以 **偏移 Y X** 特別看 Y 軸的投影，並沿著局部投影 X 軸偏移該投影。
>
>換個角度想&#x200B;**，偏移 Y X** 在水平&#x200B;**上偏移 Y 投影**，**而偏移 Y Y 在**&#x200B;垂直&#x200B;**方向偏移 Y**&#x200B;投影。

### 軸 Z

<table>

>[!NOTE]

> 偏移參數的標題中有兩個軸。 第一個定義投影軸，第二個定義偏移軸。 偏 **移Z Y** 特別看Z軸的投影，並沿著局部投影Y軸偏移該投影。
>
>另一種理解方式是&#x200B;**，偏移Z X**&#x200B;在水平&#x200B;**方向偏移** Z投影，**而偏移Z Y**&#x200B;則在垂直&#x200B;**方向偏移** Z投影。
