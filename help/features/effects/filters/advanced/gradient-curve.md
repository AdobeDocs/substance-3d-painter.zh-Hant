<td width="33.33%" style="border: 0;" valign="top">

<b>在：</b> 效果/預設、重新映射、範圍

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

梯度曲線過濾器透過可自訂的梯度曲線重新映射數值。

它用於貼圖層或遮罩內部（黑白輸出），用來重新映射帶有預設曲線形狀的灰階值。

</td>
</tr>
</table>

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>預設音色：</b> | 選擇曲線預設。 |
| <b>反轉：</b> | 切換結果的反轉。 |
| <b>平衡：</b> | 調整黑白效果的平衡，類似亮度調整。 |
| <b>對比：</b> | 調整結果的對比度或衰減。 |
