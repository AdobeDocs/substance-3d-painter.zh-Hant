## 說明

遮罩輪廓濾鏡會從遮罩的邊緣建立輪廓。

它用於貼圖圖層或遮罩內部（黑白輸出），以產生遮罩形狀周圍的內側、外側或雙重輪廓。

</td>

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>面罩位置：</b> | 選擇輪廓是出現在遮罩邊緣的外側、內側，還是兩側。 |
| <b>從黑色開始：</b> | 切換輪廓是否從黑色開始。 這實際上就像是一種反轉切換。 |
| <b>門檻：</b> | 調整用來偵測遮罩邊緣的閾值。 |
| <b>寬度：</b> | 調整輪廓的寬度。 |
| <b>模糊：</b> | 調整套用在輪廓上的模糊度。 |
| <b>曲線形狀：</b> | 調整輪廓衰減的形狀。 |
