# 斜面光滑

<table>

<td width="33.33%" style="border: 0;" valign="top">

<b>在：</b> 效果/斜角、平滑、距離、灰階

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

斜面平滑濾波器會從遮罩邊界向外、向內或兩者同時繪製漸層。

它用於貼圖層或遮罩內部（黑白輸出），從遮罩邊緣創造出平滑的斜面漸層。

</td>
</tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>距離圖：</b> 灰階 | 使用自訂材質或錨點。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>導演：</b> | 選擇遮罩邊框應該擴大的一側。 |
| <b>距離：</b> | 調整斜面膨脹的距離。 |
| <b>平滑化：</b> | 調整施加在遮罩上的平滑強度。 |
| <b>曲線偏移：</b> | 調整遮罩邊界向內或向外。 |
| <b>曲線形狀：</b> | 選擇斜坡採用捏曲或圓弧。 |
| <b>口罩門檻：</b> | 調整用於偵測遮罩邊界的值。 |
| <b>距離地圖乘數：</b> | 調整距離地圖對最大距離的影響。 |
| <b>斜面包裹：</b> | 切換斜面磚是橫向還是垂直排列。 |
