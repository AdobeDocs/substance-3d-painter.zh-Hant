## 說明

風格化濾鏡賦予材質手繪、風格化的外觀。

它用於貼圖層，加入畫筆筆觸、平滑度變化、色彩重映射及烘焙光照效果。

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>風格化：</b> | 調整濾鏡的全域強度。 |
| <b>筆觸：</b> | 調整筆觸效果的整體強度。 |
| <b>順滑度：</b> | 調整平滑效果的整體強度。 |
| <b>上色：</b> | 調整整體著色效果的強度。 |
| <b>漸層：</b> | 調整漸層效果的整體強度。 |
| <b>烘焙燈光：</b> | 調整烘焙燈光效果的整體強度。 |
| <b>邊緣與空洞：</b> | 調整邊緣和空洞效果的整體強度。 |

### 筆觸

| 參數名稱 | 說明 |
| --- | --- |
| <b>中擊次數：</b> | 調整濾鏡使用的筆觸數量。 |
| <b>Strokes 模式：</b> | 選擇濾鏡所使用的筆觸類型。 |
| <b>筆劃選擇：</b> | 在使用多筆觸時，選擇要投射的筆觸形狀。 |
| <b>筆劃選擇：</b> | 使用單一筆劃時，選擇要投影的筆觸形狀。 |
| <b>中風量表：</b> | 調整筆觸的比例。 |
| <b>非均勻尺寸：</b> | 切換投影筆觸的非均勻縮放。 |
| <b>筆劃大小：</b> | 調整投影筆觸的長寬比。 |
| <b>中風量表隨機：</b> | 調整筆觸上隨機比例變化的程度。 |
| <b>筆觸跟隨表面：</b> | 切換筆觸的對齊到網格方向。 |
| <b>動作輪流：</b> | 調整筆觸旋轉角度。 |
| <b>筆劃旋轉隨機：</b> | 調整刷筆筆觸所施加的隨機旋轉量。 |
| <b>投影硬度：</b> | 調整郵票投影的硬度。 |
| <b>正常閾值：</b> | 調整用於劃槳投影的正常閾值。 |

### 筆觸效果

| 參數名稱 | 說明 |
| --- | --- |
| <b>色彩自訂：</b> | 切換筆觸使用自訂顏色。 |
| <b>顏色變化：</b> | 調整筆觸與底色融合的程度。 |
| <b>色彩不透明度：</b> | 調整套用在筆觸上的自訂顏色的不透明度。 |
| <b>顏色：</b> | 調整筆觸所套用的自訂顏色。 |
| <b>顏色隨機：</b> | 調整筆觸上隨機色彩變化的程度。 |
| <b>粗糙度自訂：</b> | 切換使用筆觸上的自訂粗糙度值。 |
| <b>粗糙度變化：</b> | 調整筆觸間的粗糙度變化。 |
| <b>粗糙度：</b> | 調整筆觸的粗糙度值。 |
| <b>金屬客製化：</b> | 切換筆觸上自訂金屬值。 |
| <b>金屬變化：</b> | 調整筆觸上的金屬變化。 |
| <b>金屬色：</b> | 調整筆觸的金屬度。 |
| <b>一般自訂：</b> | 切換筆觸的額外法線貼圖選項。 |
| <b>正常變異：</b> | 調整正常通道中筆觸的強度。 |
| <b>普通隨機：</b> | 調整筆觸上施加的隨機法線變化量。 |
| <b>混合模式（一般）：</b> | 選擇用於筆觸的正常混合模式。 |

### 平滑度

| 參數名稱 | 說明 |
| --- | --- |
| <b>色彩順滑度：</b> | 調整套用在基色上的桑原平滑效果。 |
| <b>粗糙度 平滑度：</b> | 調整套用在粗糙度上的桑原平滑效果。 |
| <b>金屬質地的順滑度：</b> | 調整套用在金屬色上的桑原平滑效果。 |
| <b>高度平滑度：</b> | 調整套用在高度上的桑原平滑效果。 |
| <b>正常平滑度：</b> | 調整套用在普通難度的桑原平滑效果。 |
| <b>環境遮蔽的平滑度：</b> | 調整桑原平滑效果對環境遮蔽的效果。 |

### 上色

| 參數名稱 | 說明 |
| --- | --- |
| <b>色彩不透明度：</b> | 調整套用到基礎色的色彩覆蓋不透明度。 |
| <b>顏色：</b> | 選擇用來覆蓋基底色的顏色。 |
| <b>垃圾搖滾變化：</b> | 選擇用於顏色變化的圖案形狀。 |
| <b>垃圾搖滾的不透明性：</b> | 調整Base Color中基於圖案的色彩變化量。 |
| <b>垃圾搖滾色彩：</b> | 在基底色中調整圖案色彩變化的色調。 |
| <b>耕作量：</b> | 調整對應到顏色變化中的圖案數量。 |
| <b>圖案量表：</b> | 調整映射到顏色變化中的圖案比例。 |

### 梯度

| 參數名稱 | 說明 |
| --- | --- |
| <b>漸層模式：</b> | 選擇漸層是使用一種顏色還是兩種顏色。 |
| <b>顏色：</b> | 調整第一個漸層顏色。 |
| <b>色彩不透明度：</b> | 調整第一個漸層顏色的不透明度。 |
| <b>色彩混合模式：</b> | 選擇第一個漸層顏色的混合模式。 |
| <b>顏色2：</b> | 調整第二個漸層顏色。 |
| <b>色彩2 不透明度：</b> | 調整第二個漸層色的不透明度。 |
| <b>色彩二混合模式：</b> | 選擇第二色漸變色的混合模式。 |
| <b>水平旋轉：</b> | 調整梯度的水平旋轉。 |
| <b>垂直旋轉：</b> | 調整梯度的垂直旋轉。 |
| <b>梯度反轉：</b> | 切換漸層遮罩的反轉。 |
| <b>梯度偏移：</b> | 調整漸層遮罩的偏移量。 |
| <b>漸變對比：</b> | 調整漸層遮罩的對比度。 |

### 邊緣與空腔

| 參數名稱 | 說明 |
| --- | --- |
| <b>模式：</b> | 選擇要在基底色中映射空腔、邊緣或兩者。 |
| <b>邊緣與蛀牙的對比：</b> | 調整邊緣和空腔遮罩的對比度。 |
| <b>蛀牙不透明度：</b> | 調整融合成基色的空腔強度。 |
| <b>蛀牙擴散：</b> | 調整融合成基色的空腔分布。 |
| <b>蛀牙中的刷痕：</b> | 調整刷筆遮蔽凹腔融合的程度。 |
| <b>自訂凹槽顏色：</b> | 切換空腔中自訂顏色的使用。 |
| <b>蛀牙顏色：</b> | 調整凹槽中混合的自訂顏色。 |
| <b>邊緣不透明度：</b> | 調整融合到基色中的邊緣強度。 |
| <b>邊緣讓開：</b> | 調整融合到基色的邊緣擴散。 |
| <b>邊緣的筆觸：</b> | 調整筆觸遮蔽邊緣融合的程度。 |
| <b>自訂邊緣顏色：</b> | 在邊緣切換使用自訂顏色。 |
| <b>邊緣顏色：</b> | 調整融合在邊緣的自訂顏色。 |
