## 說明

MatFX 防鏽老化過濾器會在材料上造成生鏽堆積和風化。

它用於紋理層或材料堆疊，以增加腐蝕、滴落和老化效果。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>模糊強度：</b> | 調整模糊效果的強度。 |
| <b>模糊膜：</b> | 切換模糊包裝、開啟或關閉。 當模糊包膜開啟時，它會從材質的另一側取樣像素。 |
| <b>鏽蝕擴散：</b> | 調整鏽蝕擴散。 |
| <b>均勻傳播：</b> | 調整攤開的平滑度。 |
| <b>清漆傷害等級：</b> | 調整清漆傷害等級。 |
| <b>滴水強度：</b> | 調整滴水強度。 |
| <b>滴注樣本量：</b> | 調整滴漏取樣的量。 |
| <b>滴水順滑度：</b> | 調整滴水的順滑度。 |

### 混合

| 參數名稱 | 說明 |
| --- | --- |
| <b>正常強度：</b> | 調整法線貼圖的混合強度。 |
| <b>環境遮蔽強度：</b> | 調整 AO 地圖的混合強度。 |
| <b>身高強度：</b> | 調整高度圖的混合強度。 |

**金屬粗糙度**

| 參數名稱 | 說明 |
| --- | --- |
| <b>底色強度：</b> | 調整基色強度。 |
| <b>粗糙度強度：</b> | 調整粗糙度貼圖的混合強度。 |
| <b>金屬強度：</b> | 調整金屬貼圖的混合強度。 |
