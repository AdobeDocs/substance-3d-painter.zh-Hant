# MatFX 剝落的油漆

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![MatFX 剝落的油漆圖示](./Resources/icon_matfx_peeling_paint.png "MatFX 剝落的油漆")

<b>收錄於：</b> 特效/模糊、灰階

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

MatFX 剝落油漆濾鏡會產生剝落和剝落的油漆效果。

它用於貼圖層或材質堆疊，以模擬剝落的油漆、剝落的塗層，並暴露底層材質。

</td>
</tr>
</table>

>[!NOTE]
>
> 為了曝光底層材質，可以在群組內使用 MatFX 剝皮塗料。 在群組外、層堆疊下方的層會暴露出來，因為剝落的油漆會從表面拉開。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>模糊強度：</b> | 調整模糊效果的強度。 |
| <b>模糊膜：</b> | 切換模糊包膜。 啟用時，效果會取樣材質另一側的像素。 |
| <b>剝落層：</b> | 調整整體剝皮程度。 |
| <b>剝離距離：</b> | 調整油漆剝落的程度。 |
| <b>薄片等級：</b> | 調整剝落的程度。 |
| <b>氣泡密度：</b> | 調整氣泡的密度。 |
| <b>剝落密度：</b> | 調整剝落的密度。 |
| <b>剝落 X 個數量：</b> | 調整X軸的剝落量。 |
| <b>剝落的Y量：</b> | 調整Y軸的剝落量。 |
| <b>使用曲率：</b> | 切換曲率輸入的使用。 |
| <b>曲率距離：</b> | 調整曲率取樣距離。 |
| <b>曲率對比：</b> | 調整曲率輸入的對比度。 |

### 技術參數

這些參數允許你修改剝離材料的頂表面。

| 參數名稱 | 說明 |
| --- | --- |
| <b>亮度：</b> | 調整亮度。 |
| <b>對比：</b> | 調整結果的對比度或衰減。 |
| <b>色相偏移：</b> | 調整色相偏移。 |
| <b>飽和度：</b> | 調整飽和度。 |
| <b>正常強度：</b> | 調整正常強度。 |
| <b>身高範圍：</b> | 調整效果所使用的高度範圍。 |
| <b>身高位置：</b> | 調整效果所使用的高度位置。 |
| <b>環境遮蔽強度：</b> | 調整環境遮蔽的強度。 |
