# MatFX 細節邊緣磨損

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="./Resources/icon_matfx_detail_edge_wear.png" alt="MatFX 細節邊緣磨損圖示" title="MatFX 細節邊緣磨損"/><br><strong>在：</strong> 效果/磨損、邊緣、材質</td>
    <td style="border: 0;" valign="top">說明<br>MatFX 細節邊緣磨損濾鏡能產生可融合成材料的磨損邊緣細節。<br>它用於貼圖層或材質堆疊，以增加邊緣磨損、泥漿破碎，以及由遮罩和曲率資料驅動的輔助材質調整。</td>
  </tr>
</table>

>[!NOTE]
>
> 要讓 MatFX 細節邊緣磨損濾鏡產生可見效果，濾鏡下方的圖層堆疊中必須存在不同的法線資訊。 如果正常頻道沒有資料或變化，濾波器就無法找到可損壞的邊緣，也不會有明顯的影響。

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| **模糊強度：** | 調整模糊效果的強度。 |
| **模糊膜：** | 切換模糊包膜。 啟用時，效果會取樣材質另一側的像素。 |
| **輸入模式：** | 選擇用來驅動磨損效果的輸入模式。 |
| **磨損程度：** | 調整整體磨損程度。 |
| **戴對比度：** | 調整戴口罩的對比度。 |
| **邊緣平滑度：** | 調整磨損邊緣的光滑程度。 |
| **垃圾搖滾的份量：** | 調整磨損時添加的髒污量。 |
| **垃圾搖滾等級：** | 調整垃圾搖滾圖案的比例。 |

### 材質

**PBR 金屬粗糙度**

|  |  |
| --- | --- |
| **底色：** | 調整基底色彩的貢獻。 |
| **金屬色：** | 調整金屬值。 |
| **粗糙度：** | 調整粗糙度值。 |

**PBR 鏡面光澤**

|  |  |
| --- | --- |
| **擴散性：** | 調整漫射的貢獻。 |
| **鏡面色彩：** | 調整鏡面顏色。 |
| **光澤感：** | 調整光澤度。 |

### 設定

|  |  |
| --- | --- |
| **發電機遮罩控制：** | 調整發電機遮罩的影響。 |
| **產生器遮罩對比度：** | 調整發電機遮罩的對比度。 |
| **發電機遮罩模糊：** | 調整施加在發電機遮罩上的模糊度。 |
| **Alpha背景值：** | 調整背景 alpha 值。 |
| **彎曲強度：** | 調整曲率輸入的強度。 |
| **反曲率：** | 切換曲率輸入的反轉。 |
| **結合曲率：** | 切換結合反轉曲率與非反轉曲率資料。 |
| **正常強度：** | 調整正常強度。 |
| **AO擴散：** | 調整環境遮蔽效應的擴散範圍。 |
