## 說明

MatFX HBAO 濾波器可根據高度資訊產生基於地平線的環境遮蔽。

它用於材質圖層或遮罩，根據來源通道或高度資訊增加深度並接觸陰影。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>模糊強度：</b> | 調整結果的模糊強度。 |
| <b>模糊膜：</b> | 切換模糊包膜。 啟用時，效果會取樣材質另一側的像素。 |
| <b>頻道來源：</b> | 選擇用於產生遮蔽的通道來源。 |
| <b>使用世界單位：</b> | 切換使用世界空間單位。 |
| <b>高度深度：</b> | 調整感知高度輸入的深度。 |
| <b>半徑：</b> | 調整遮蔽效應的取樣半徑。 |
| <b>強度：</b> | 調整閉合強度。 |
| <b>救濟平衡：</b> | 調整救濟繳款的餘額。 |
