## 說明

MatFX Shut Line 濾波器可在材質上產生面板線或接縫細節。

它用於材質圖層或材質堆疊，以添加封閉線條、壓紋接縫，以及支撐高度和色彩細節。

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>腔寬度：</b> | 調整空腔的寬度。 |
| <b>坡度強度：</b> | 調整斜率效應的強度。 |
| <b>壓印強度：</b> | 調整壓紋的強度。 |
| <b>身高強度：</b> | 調整高度效應的強度。 |

### 材質

| 參數名稱 | 說明 |
| --- | --- |
| <b>線條顏色：</b> | 調整線條顏色。 |
| <b>資料來源不透明度：</b> | 調整原始素材的透明度。 |
