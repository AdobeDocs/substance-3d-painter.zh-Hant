## 說明

MatFX 水彩濾鏡以水彩風格化原色。

它用於材質層，以創造水彩滲透、紙張互動及柔和的繪畫邊緣。

</td>
</tr>

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>顏料不透明度：</b> | 調整顏料的透明度。 |
| <b>紙張吸收：</b> | 調整紙張吸收顏料的強度。 |
| <b>累積類型：</b> | 選擇累積方法。 |
| <b>邊界差：</b> | 調整油漆邊框的分布。 |
| <b>邊界密度：</b> | 調整油漆邊框的密度。 |
| <b>展示十字漆邊緣：</b> | 切換交叉塗裝邊緣的顯示。 |
| <b>隱藏紙張：</b> | 切換紙張紋理的可見性。 |
| <b>客製化紙張：</b> | 切換使用自訂紙張材質。 |
