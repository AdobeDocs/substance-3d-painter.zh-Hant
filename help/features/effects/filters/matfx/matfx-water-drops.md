# MatFX 水滴

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![MatFX 水滴圖示](./Resources/icon_matfx_water_drops.png "MatFX 水滴")

<b>收錄於：</b> 特效/模糊、灰階

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 說明

MatFX 水滴過濾器會在材料上產生水滴和逕流效應。

它用於貼圖層或材質堆疊，以添加液滴、方向條紋及濕面變化。

</td>
</tr>
</table>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>環境遮蔽：</b> 灰階 | 使用烘焙的環境遮蔽貼圖。 |
| <b>世界空間法線：</b> 顏色 | 使用烘焙的世界空間法線貼圖。 |
| <b>位置：</b> 顏色 | 使用烘焙位置圖。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>掉落量：</b> | 調整水滴的量。 |
| <b>掉落 X 級：</b> | 調整掉落的X比例。 |
| <b>降低 Y 尺度：</b> | 調整掉落的 Y 比例。 |
| <b>掉落量表隨機：</b> | 調整掉落中隨機鱗片變化的程度。 |
| <b>降低方向強度：</b> | 調整水滴的方向強度。 |

### 位置

| 參數名稱 | 說明 |
| --- | --- |
| <b>影響X：</b> | 調整位置輸入的 X 影響。 |
| <b>影響 Y：</b> | 調整位置輸入的 Y 影響。 |
| <b>影響Z：</b> | 調整位置輸入的Z軸影響。 |

### 積水

| 參數名稱 | 說明 |
| --- | --- |
| <b>強度：</b> | 調整積水強度。 |
| <b>讓分：</b> | 調整積水的擴散範圍。 |
| <b>AO基底強度：</b> | 調整環境遮蔽對積水的影響程度。 |

### 世界空間

| 參數名稱 | 說明 |
| --- | --- |
| <b>掩蓋強度：</b> | 調整世界空間遮罩的強度。 |
| <b>最高強度：</b> | 調整朝上區域的落差強度。 |
| <b>底部強度：</b> | 調整朝下區域的落差強度。 |
| <b>前葉強度：</b> | 調整正面區域的落差強度。 |
| <b>背部強度：</b> | 調整背向區域的落差強度。 |
| <b>右心強度：</b> | 調整右側區域的落差強度。 |
| <b>左側強度：</b> | 調整左向區域的落差強度。 |

### 材質

| 參數名稱 | 說明 |
| --- | --- |
| <b>下降基礎色彩扭曲強度：</b> | 調整滴落下的底色扭曲強度。 |
| <b>降低旋轉向量圖乘法：</b> | 調整施加在下墜旋轉向量地圖上的乘數。 |
| <b>落差高度強度：</b> | 調整落差高度效應的強度。 |
| <b>降低粗糙度：</b> | 調整滴劑的粗糙度。 |
| <b>Drops 粗糙度融合：</b> | 調整落差粗糙度與材質的融合方式。 |
| <b>滴落金屬感：</b> | 調整滴落的金屬值。 |
| <b>Drops 金屬暈染：</b> | 調整滴落金屬值與材質的融合方式。 |
| <b>正常強度：</b> | 調整正常效應的強度。 |
