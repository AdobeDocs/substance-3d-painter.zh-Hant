## 說明

MatFX 漫畫濾鏡以漫畫風格風格化材料。

它用於材質圖層，創造出圖形化、插圖化的渲染風格，結合簡化的陰影與大膽的視覺處理。

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>環境遮蔽：</b> 灰階 | 使用烘焙的環境遮蔽貼圖。 |
| <b>曲率：</b> 灰階 | 使用烘焙的曲率貼圖。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>輸入類型：</b> | 選擇效果所使用的輸入類型。 |
| <b>輸入對比度：</b> | 調整輸入的對比度。 |
| <b>輸入亮度：</b> | 調整輸入的亮度。 |
| <b>色彩強度：</b> | 調整色彩處理的強度。 |
| <b>邊界不透明度：</b> | 調整邊界的不透明度。 |
| <b>邊境容忍：</b> | 調整邊界偵測容差。 |
| <b>邊界平滑度：</b> | 調整邊框的平滑度。 |
| <b>顏料濃度：</b> | 調整顏料效果的強度。 |
| <b>曲速：</b> | 調整曲速效果。 |
| <b>銳利度：</b> | 調整結果的銳利度。 |
| <b>輸出對比度：</b> | 調整輸出的對比度。 |
| <b>輸出亮度：</b> | 調整輸出的亮度。 |
