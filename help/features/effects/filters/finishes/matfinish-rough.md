## 說明

MatFinish 粗糙濾鏡是金屬漆面系列的一部分，用來創造粗糙金屬效果。

它用於填充層。 調整底層填充層的顏色、粗糙度、金屬質感及其他特性，然後加入濾網進行最終表面處理。

<a name="parameters"></a>

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>自訂垃圾搖滾：</b> 灰階 | 使用自訂的垃圾搖滾材質或錨點。 |
| <b>位置：</b> 顏色 | 使用烘焙的位置貼圖。 |
| <b>世界空間法線：</b> 顏色 | 使用烘焙的世界空間法線貼圖。 |

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>種子：</b> | 隨機分配一個數值，創造出不同的變化，且不改變整體設定。 |
| <b>規模：</b> | 調整整體塗層的比例。 |
| <b>Scale Grunge：</b> | 調整垃圾搖滾圖案的比例。 |
| <b>刷牙強度：</b> | 調整刷牙效果的強度。 |
| <b>刷牙經線：</b> | 調整刷子時施加的變形程度。 |
| <b>使用自訂片狀物：</b> | 切換使用自訂 Flake 輸入。 |
| <b>三平面映射：</b> | 切換三平面映射。 |
| <b>使用客製化垃圾搖滾：</b> | 切換使用自訂的 grunge 材質。 |
