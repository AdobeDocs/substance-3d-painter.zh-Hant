## 說明

MatFinish 顆粒濾鏡是金屬漆面系列的一部分，用來創造顆粒感的金屬效果。

它用於填充層。 調整底層填充層的顏色、粗糙度、金屬質感及其他特性，然後加入濾網進行最終表面處理。

## 輸入

| 輸入名稱 | 說明 |
| --- | --- |
| <b>位置：</b> 顏色 | 使用烘焙的位置貼圖。 |
| <b>世界空間法線：</b> 顏色 | 使用烘焙的世界空間法線貼圖。 |

<a name="parameters"></a>

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>種子：</b> | 隨機分配一個數值，創造出不同的變化，且不改變整體設定。 |
| <b>規模：</b> | 調整整體塗層的比例。 |
| <b>顆粒強度：</b> | 調整木紋的強度。 |
| <b>三平面映射：</b> | 切換三平面映射。 |
