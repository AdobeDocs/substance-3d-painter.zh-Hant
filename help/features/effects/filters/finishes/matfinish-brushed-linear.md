## 說明

MatFinish 拉絲線性濾鏡是金屬漆面系列的一部分，用來創造線性拉絲金屬效果。

它用於填充層。 調整底層填充層的顏色、粗糙度、金屬質感及其他特性，然後加入濾網進行最終表面處理。

## 參數

| 參數名稱 | 說明 |
| --- | --- |
| <b>種子：</b> | 隨機分配一個數值，創造出不同的變化，且不改變整體設定。 |
| <b>規模：</b> | 調整整體塗層的比例。 |
| <b>刷牙強度：</b> | 調整刷牙效果的強度。 |
| <b>長度：</b> | 調整刷痕的長度。 |
| <b>輪替：</b> | 調整刷狀圖案的旋轉方向。 |
