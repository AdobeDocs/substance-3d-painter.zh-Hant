# 通用場景描述（USD）

![](../assets/banner-usd.jpg)

Us 工作流程可在 Painter 8.3 中提供。 [USD](https://graphics.pixar.com/usd/release/intro.html) 由皮克斯開發，作為一種友善協作且可互換的格式，能承載多種不同類型的資料。

在 Painter 的語境下，現在可以：

* [建立專案](../getting-started/project-creation.md)，利用 USD 專屬功能，例如範圍與變體選擇、子類別等級及動畫幀。
* [用 USD 格式匯出](../export/export-window/export-settings.md) 材質和材質。
* 此外，USD 也被加入為僅限網格匯出的新檔案格式。
