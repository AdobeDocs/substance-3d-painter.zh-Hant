# 3Dconnexion 的 SpaceMouse®

![](../assets/spacemouse-banner.jpg)

3Dconnexion 的 SpaceMouse® 是一款能輕鬆在 3D 中導航的裝置。 它可用於操作應用程式視窗中的攝影機/3D 模型。

* SpaceMouse® 自 7.4.2 版本起獲得支援。
* 要正確使用這台裝置，請務必安裝 3Dconnexion[&#128279;](https://3dconnexion.com/uk/drivers/) 最新的驅動程式。

>[!NOTE]
>
> 使用緊湊模型且需要頻繁旋轉環境地圖的使用者，可能會將 SHIFT 鍵指定在左側按鈕。

## 教學

## 概觀

主控制旋鈕或 SpaceMouse® 讓你能旋轉、平移和放大視窗，這是一般滑鼠/觸控筆和鍵盤控制無法做到的。 此裝置可與滑鼠及觸控筆平板搭配使用。

所有型號與版本都應與應用程式相容：

| 模型 | 說明 | 視覺 |
| --- | --- | --- |
| **緊湊模型** | 基礎型號搭配旋鈕控制。 | <div><img class="confluence-embedded-image" data-preserve-html="true" src="../assets/3Dconnexion_SpaceMouse-Wireless-400x400.png" width="200"/></div> |
| **專業模式** | 旋鈕控制和鍵盤快捷鍵的額外按鈕。 | <div><img class="confluence-embedded-image" data-preserve-html="true" src="../assets/3Dconnexion_SpaceMouse-Pro-400x400.png" width="200"/></div> |
| **企業模式** | 旋鈕控制、額外按鈕與情境顯示功能。 | <div><img class="confluence-embedded-image" data-preserve-html="true" src="../assets/3Dconnexion_SpaceMouse-Enterprise-400x400.png" width="200"/></div> |

>[!NOTE]
>
> Compact、Pro 和 Enterprise 型號都經過測試與驗證，能與應用程式正常運作。

## 環狀選單

選單可直接從裝置存取：

* 在緊湊型模型中，點擊左側按鈕，從徑向選單中選擇屬性：

  ![](../assets/image2022-3-3-15-14-41.png){width="250px"}
* 在 Pro 和 Enterprise 型號上，可以按下選單按鈕進入屬性選單。

或者，在系統托盤中（系統時鐘旁邊）右鍵點擊 3Dconnexion 圖示，選擇 **開啟 3Dconnexion 設定**。 這個選單會根據最後一個啟用視窗而設，根據上下文而定。 標題列會標示對應的程式，如果不是 Adobe Substance 3D Painter，請切換到 Painter 視窗，然後回到設定視窗：

## 預設設定

![](../assets/image2022-3-3-10-23-48.png){width="400px"}

在 SpaceMouse® 的設定面板中，Painter 的預設設定可在最新版本驅動程式中取得。 不需要額外設定，只要連接裝置即可即插即用。

請確定從上方下拉選單選對裝置，預設情況下應該會選對裝置。

「速度」滑桿會改變所有軸向和方向的靈敏度。

### 進階設定

點擊「進階設定」按鈕，可以調整主要控制的細節行為。

任何預設設定都可以修改。 分頁中有兩個重要區塊： **導航模式** 與 **旋轉中心**。

#### 導航模式

![](../assets/image2022-3-3-15-5-18.png){width="400px"}

定義旋鈕在三維中的行為：

| 背景設定 | 說明 |
| --- | --- |
| 物件模式 | 旋鈕本身就是 3D 物件本身，它是預設的。 |
| 相機模式 | 自由地以3D方式控制攝影機。 |
| 目標相機模式 | 控制攝影機，總是鎖定 3D 空間中的某個點。 |
| 直升機模式 | 在3D空間中操控直升機。 |
| 鎖地平線 | 鎖定相機，讓地平線永遠是水平的。 Painter 的設定裡已經有類似的選項，但這裡可以另外控制。 預設是鎖定的。 |

#### 旋轉中心

![](../assets/image2022-3-3-10-25-26.png){width="400px"}

定義小型樞軸圖示行為：

| 背景設定 | 說明 |
| --- | --- |
| 自動 | 自動移動樞軸或相機目標，關閉時它總是黏在網格原點的樞軸上。 |
| 永遠展示 | 即使不與裝置互動，樞軸點也會在 3D 視窗中顯示。 |
| 動態秀 | 樞軸點僅在與裝置互動時顯示於 3D 視口中。 這是預設選項。 |
| 隱藏 | 完全移除 3D 視窗中的樞軸點。 |

>[!NOTE]
>
> 樞軸點是專門為 Painter 設計的，但如果需要也可以隱藏。
