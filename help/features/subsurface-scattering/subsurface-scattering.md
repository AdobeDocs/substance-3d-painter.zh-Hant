# 次表面散射

![](../../assets/sss-sarah.jpg){width="500px"}

&#x200B;>> 

（製作人員：士兵，[作者：里貝羅勒斯·里奧]（https://www.artstation.com/artwork/xNYDm 年）

Substance 3D Painter 在即時&#x200B;**視口**&#x200B;與 [Iray 渲染器](../../features/iray-renderer/iray-renderer.md)中都支援&#x200B;**次表面散射**。

次表面散射是一種光在穿透物體或表面時產生的機制。 與金屬表面反射不同，部分光線被材料吸收後  **散射到內部**  。 這種行為通常以縮寫  **SSS**  為名，代表「  **S**  ub  **S**  urface  **S**  cattering」。 現實生活中許多材料都有表面下散射，例如表皮或蠟。
