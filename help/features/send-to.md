# 發送至

![旗幟圖像](../assets/sendto_banner.jpg)

<b>Send to</b> 是用來輕鬆將資源從專案匯出與匯入其他應用程式的動作，避免手動操作。 Send to 可用於將 3D 模型及其材質匯出到其他渲染應用程式，或從 Substance 3D Designer 接收 Substance 材質。

傳送至動作可透過 <b>檔案>送出</b> 選單。

目前支援 <b>的 Send to</b> 有：

* 傳送到 <b>Photoshop</b>
* 傳送至 <b>Substance 3D Stager</b>
* 傳送到 <b>After Effects</b>

Painter 也可以從其他應用程式獲取資源，例如：

* <b>Substance 3D 設計師</b>
* <b>Substance 3D 取樣器</b>

欲了解更多接收資源的資訊，請參閱 [專門的文件頁面](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md)。

>[!NOTE]
>
> 部分送至工作流程僅在 Adobe 版 Painter 上可用，因為與 Creative Cloud Desktop 軟體的技術依賴。
> 
> 此外，若未安裝所需軟體，送出選單中的某些操作可能無法使用。
