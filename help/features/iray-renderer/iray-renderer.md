# Iray 渲染器

![](../../assets/iray-mode.jpg){width="600px"}

**Iray** 是由 Nvidia](http://www.nvidia.com/object/nvidia-iray.html) 開發[的 GPU 加速路徑追蹤渲染器。\
透過 Iray，可以在場景中創造出極高的光照精度，且能以高解析度（高解析度）呈現。

## Iray 模式

為了啟動 Iray，必須改變 Substance 3D Painter 的模式。\
這可以透過多種壓制方式來完成：

* 按  **F10 鍵**  （或  **按 F9**  回到繪畫模式）
* 點擊主工具列中的相機圖示
* 透過使用模式選單

## Iray 參數

Iray 使用特定的參數，但同時也使用與 Substance 3D Painter 一般視窗相同的特性。

* [Iray 設定](iray-settings.md)
* [檢視器與 MDL 設定](viewer-and-mdl-settings.md)

## 顯示設定

顯示設定讓你控制攝影機和後製特效的設定。\
它們與一般視窗渲染相同，因此能保持同步並避免不必要的光照差異。

更多細節請參閱專屬頁面： [顯示設定](../../interface/display-settings/display-settings.md)
