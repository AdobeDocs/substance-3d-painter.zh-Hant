# 虛擬記憶體不足時當機

如果  **分頁**  檔案（  **交換**  記憶體/  **虛擬**  記憶體）設定的值  **過低**  ，Substance 3D Painter 可能會不穩定。\
建議讓作業系統負責這些設定（通常是預設情況下）。 Substance 3D Painter 至少需要 **&#x200B;**&#x200B;**16GB** 虛擬記憶體才能正常運作。

## 如何在 Windows 上更改虛擬記憶體大小？

>[!NOTE]
>
> 在 Windows 上更改虛擬記憶體大小需要重新啟動電腦。

請透過以下步驟存取虛擬記憶體設定

1. 右鍵點擊電腦 **/此電腦** 圖示，選擇 **屬性**
1. 選擇「進階系統設定」**&#x200B;**
1. 點擊&#x200B;**表演**&#x200B;區的設定按鈕&#x200B;**&#x200B;**
1. 點選進 **階** 標籤
1. 點選虛擬記憶體&#x200B;**區塊中的變更** **&#x200B;**

現在可以以下兩種方式：

* 啟用「自動管理所有磁碟分頁檔案大小」的勾選選項&#x200B;**&#x200B;**

**或**

* 選擇你想更改虛擬記憶體大小的硬碟，選擇 **系統管理大小** ，然後點選 **設定** 按鈕。
