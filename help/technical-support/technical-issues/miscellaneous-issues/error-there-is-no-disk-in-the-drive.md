# 錯誤：光碟機裡沒有磁碟

在 Windows 上，有時會遇到這個錯誤：

「光碟機裡沒有磁碟。 請將磁碟插入X碟。」

![](../../../assets/disk-drive-error.png)

有幾件事需要檢查以消除這個錯誤：

* 確認你的磁碟機代號設定正確（參見 <https://support.microsoft.com/en-us/kb/330137> ）
* 確認 Substance 3D Painter 中之前使用過的任何位置是否有效（例如「近期檔案」清單）
