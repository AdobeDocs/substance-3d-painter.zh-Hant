# 無法將檔案拖放到書架上

在  **Windows 8 和 Windows 10**  上，如果你以管理員模式執行 Substance 3D Painter，軟體的安全等級可能會比 Windows 檔案總管高。 因此 Windows 不允許在這些應用程式間拖放檔案。

要解決這個問題，你可以選擇：

* 正常執行 Substance 3D Painter（無管理員權限）。
* 關閉 UAC（不建議&#x200B;**這麼**&#x200B;做）。

>[!NOTE]
>
> 也可以透過開啟匯入視窗來匯入資源：
> 
> 1. 點選選單「檔案」
> 1. 選擇「匯入資源......」
> 1. 在匯入視窗點選「新增資源」來選擇你的檔案
