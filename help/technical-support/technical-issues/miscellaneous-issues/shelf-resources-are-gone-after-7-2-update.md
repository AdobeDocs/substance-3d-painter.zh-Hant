# 7.2 更新後，架子資源就消失了

本頁說明資源可能消失的原因及恢復方法。

更新至 7.2 版（或更新版本）後，書架上的自訂資源如 alpha、過濾器、材料、智慧材質甚至智慧口罩可能已經消失。 這是因為新版本重設了偏好設定，檔案現在放在不同的資料夾裡。 舊資源只會被忽略，可以透過手動複製檔案來還原。 要做到這點，請參考 [遷移指南](../../../pipeline-and-integration/resource-management/preferences-and-content-migration.md)。
