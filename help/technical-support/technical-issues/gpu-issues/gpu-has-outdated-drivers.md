# GPU 的驅動程式過時了

![](../../../assets/driver-outdated.png){width="500px"}

啟動 Substance 3D Painter 時，會跳出一個視窗，提示 GPU 驅動程式過時。 此訊息僅表示軟體要求安裝最低版本的 GPU 驅動程式。 我們建議盡可能更新顯示卡驅動程式到最新版本，以獲得最佳的使用體驗。

| *供應商* | *連結* |
| --- | --- |
| **NVIDIA** | [http://www.nvidia.com/Download/index.aspx](http://www.nvidia.com/Download/index.aspx?lang=en-us) <ul data-preserve-html="true"><li data-preserve-html="true"><strong> GeForce </strong> ：建議使用「Studio Drivers」（SD）版本。</li><li data-preserve-html="true"><strong> Quadro </strong> ：「Optimal Driver from Enterprise」（ODE）版本推薦。</li></ul> |
| **AMD** | <http://support.amd.com/en-us/download> |
| **英特爾** | <https://downloadcenter.intel.com/> |

>[!NOTE]
>
> 有些電腦<b>可能有兩顆</b> GPU：一顆整合式（像是 Intel 晶片組），另一顆是獨立型（像 Nvidia 顯示卡）。 <b>兩者</b>都需要更新<b></b>，才能降低 Painter 中出現錯誤的風險。
