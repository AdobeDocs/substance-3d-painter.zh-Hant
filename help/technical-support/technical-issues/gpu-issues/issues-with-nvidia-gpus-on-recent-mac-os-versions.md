# 近期 Mac OS 版本中 Nvidia GPU 的問題

在 Mac OS 下，蘋果透過驗證 GPU 驅動程式來提供 GPU 驅動程式，前提是 GPU 建構程式提供。 自 Mac OS Mojave 以來，蘋果尚未驗證近期 Nvidia GPU 的任何新驅動程式。 很可惜 Substance 3D Painter 需要更新的 GPU 驅動才能正常運作。

欲了解更多資訊，請參閱以下頁面：

* [Mac OS](https://support.apple.com/en-us/HT208898)  支援的 GPU 列表。
* [Mac OS](https://support.apple.com/en-us/HT208544)  上的外接顯示卡使用。
