# 與背景應用程式的衝突

有些在背景執行的應用程式可能會干擾 Substance 3D Painter，造成問題。 防間諜軟體與防毒軟體常分析低階程序，導致延遲，因此停用此軟體有助於提升使用 Painter 的效能。\
這裡有一份已知可能讓 Painter 當機或至少減緩其[](../technical-issues/startup-issues/software-conflicts.md)速度的應用程式清單。
