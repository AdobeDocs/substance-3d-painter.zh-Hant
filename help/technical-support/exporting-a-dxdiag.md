# 匯出 DXDiag

本頁說明什麼是 DXDiag 以及如何產生它。

DXDiag 是 Windows 上建立的診斷工具，提供關於你電腦和 GPU 配置的資訊。

以下是客服要求匯出的步驟：

1. 到「開始>執行」，在&#x200B;**「開啟」**&#x200B;欄位輸入&#x200B;**「dxdiag」（**&#x200B;不加引號），然後按下確定鍵
1. 等 **「綠色」** 進度條載入完成後，按下 **「儲存所有資訊...」** 按鈕/鈕扣
1. 請用 **一些有用的資訊來命名檔案，例如你的名字和日期，然後按「儲存」** 按鈕儲存在你能找到的地方，比如桌面
1. 按下 **「退出」** 按鈕即可退出此應用程式
