# 透過手動編輯偏好設定來新增資源路徑

在不開啟應用程式的情況下，也可以新增額外的自訂書架或資產路徑。

為此，它需要編輯應用程式偏好設定（且各平台儲存方式不同）。 新增後，新書架應該會出現在主偏好設定的書架清單中。 更多詳情請參見此頁面： [函式庫配置](../../../interface/settings/libraries-configuration.md)

>[!NOTE]
>
> 網路路徑不支援，務必使用掛載路徑以避免問題。 參見： [從網路](../../../technical-support/workflow-issues/project-issues/loading-files-from-a-network.md)載入檔案。
